Módulos (mod, pub, use)

Quando o programa cresce, um arquivo só fica difícil de ler. Módulos dividem o código em partes com nome, como pastas numa gaveta. Em Rust, tudo dentro de um módulo é privado por padrão: só o que você marca com pub pode ser usado de fora.

Você vai aprender
  • A criar módulos com mod e a expor itens com pub.
  • Caminhos com :: (crate::, super::) e atalhos com use.
  • A mover um módulo para o seu próprio arquivo.

1. Um módulo no mesmo arquivo

mod geometria {
    pub fn area_quadrado(lado: f64) -> f64 {
        lado * lado
    }

    pub fn area_circulo(raio: f64) -> f64 {
        PI_APROX * raio * raio
    }

    const PI_APROX: f64 = 3.14;
}

fn main() {
    println!("{}", geometria::area_quadrado(3.0));
    println!("{}", geometria::area_circulo(2.0));
}

3. Structs: campos também são privados

mod loja {
    pub struct Produto {
        pub nome: String,
        preco_centavos: u32,
    }

    impl Produto {
        pub fn new(nome: &str, preco: f64) -> Produto {
            Produto { nome: nome.to_string(), preco_centavos: (preco * 100.0).round() as u32 }
        }
        pub fn preco(&self) -> String {
            format!("R$ {},{:02}", self.preco_centavos / 100, self.preco_centavos % 100)
        }
    }
}

fn main() {
    let p = loja::Produto::new("caneta", 2.5);
    println!("{}: {}", p.nome, p.preco());
}
$ cargo run

Um pub struct não torna os campos públicos: cada campo precisa do seu pub. Com o preço privado, só o módulo decide como ele é guardado (aqui, em centavos), e quem usa passa pelo new e pelo método preco.

4. use e caminhos

mod escola {
    pub mod notas {
        pub fn media(v: &[f64]) -> f64 {
            v.iter().sum::<f64>() / v.len() as f64
        }

        pub fn situacao(v: &[f64]) -> &'static str {
            if media(v) >= super::MEDIA_MINIMA { "aprovado" } else { "reprovado" }
        }
    }

    pub const MEDIA_MINIMA: f64 = 7.0;
}

use escola::notas::{media, situacao};
use std::collections::HashMap as Mapa;

fn main() {
    let ana = [8.0, 6.5, 9.0];
    println!("média {:.2}: {}", media(&ana), situacao(&ana));
    println!("pelo caminho completo: {:.1}", crate::escola::notas::media(&[5.0, 6.0]));
    let mut m: Mapa<&str, u32> = Mapa::new();
    m.insert("x", 1);
    println!("{:?}", m);
}

5. Módulos em arquivos

Num projeto real, cada módulo vai para o seu arquivo. Em src/main.rs, a linha mod geometria; (com ponto e vírgula, sem chaves) diz ao compilador: “o conteúdo está em src/geometria.rs”. Um submódulo vai numa pasta com o nome do pai.

mod geometria;
mod util;

use geometria::formas::Retangulo;

fn main() {
    let r = Retangulo { largura: 3.0, altura: 2.0 };
    println!("área do retângulo: {}", r.area());
    println!("área do quadrado: {}", geometria::area_quadrado(4.0));
    util::linha();
}
pub mod formas;

pub fn area_quadrado(lado: f64) -> f64 {
    lado * lado
}
pub struct Retangulo {
    pub largura: f64,
    pub altura: f64,
}

impl Retangulo {
    pub fn area(&self) -> f64 {
        self.largura * self.altura
    }
}
pub fn linha() {
    println!("{}", "-".repeat(20));
}

Resumo

  • mod nome { … } ou mod nome; (em src/nome.rs) cria um módulo.
  • Tudo é privado por padrão; pub expõe funções, structs, campos e submódulos (E0603).
  • use encurta caminhos; crate::, super:: e self:: são pontos de partida.
