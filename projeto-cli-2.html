Projeto final: CLI (parte 2)

Na parte 1, o resumo ficou funcionando, mas todo num arquivo só e sem testes. Agora vamos deixá-lo com cara de projeto profissional: lógica numa biblioteca testável, testes de três tipos, leitura da entrada padrão (para usar com |), uma opção por variável de ambiente e o binário otimizado.

Passo 4: separar biblioteca e binário

Um pacote pode ter ao mesmo tempo src/lib.rs (uma biblioteca) e src/main.rs (o programa). O main.rs fica pequeno: lê os argumentos, chama a biblioteca e trata erros. Tudo que tem lógica vai para o lib.rs, onde é fácil de testar.

//! Resumo de textos: conta linhas, palavras e as palavras mais frequentes.
use std::collections::HashMap;
use std::error::Error;
use std::{env, fs, io};

pub struct Config {
    pub arquivo: String,
    pub top: usize,
    pub minimo: usize,
}

impl Config {
    pub fn new(args: &[String]) -> Result<Config, String> {
        if args.len() < 2 {
            return Err("faltou o nome do arquivo".to_string());
        }
        let arquivo = args[1].clone();
        let top = match args.get(2) {
            Some(t) => t.parse().map_err(|_| format!("'{t}' não é um número"))?,
            None => 5,
        };
        let minimo = match env::var("RESUMO_MIN") {
            Ok(v) => v.parse().map_err(|_| format!("RESUMO_MIN inválido: '{v}'"))?,
            Err(_) => 1,
        };
        Ok(Config { arquivo, top, minimo })
    }
}

/// Separa o texto em palavras minúsculas, sem pontuação nas pontas.
///
/// ```
/// let p = resumo::palavras("Olá, mundo! Olá.");
/// assert_eq!(p, vec!["olá", "mundo", "olá"]);
/// ```
pub fn palavras(texto: &str) -> Vec<String> {
    texto
        .split_whitespace()
        .map(|p| p.trim_matches(|c: char| !c.is_alphanumeric()).to_lowercase())
        .filter(|p| !p.is_empty())
        .collect()
}

/// Conta as palavras com pelo menos `minimo` letras e ordena:
/// mais frequentes primeiro; no empate, em ordem alfabética.
pub fn ranking(palavras: &[String], minimo: usize) -> Vec<(String, usize)> {
    let mut contagem: HashMap<&str, usize> = HashMap::new();
    for p in palavras.iter().filter(|p| p.chars().count() >= minimo) {
        *contagem.entry(p.as_str()).or_insert(0) += 1;
    }
    let mut r: Vec<(String, usize)> = contagem
        .into_iter()
        .map(|(p, n)| (p.to_string(), n))
        .collect();
    r.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(&b.0)));
    r
}

pub fn executar(config: Config) -> Result<(), Box<dyn Error>> {
    let texto = if config.arquivo == "-" {
        io::read_to_string(io::stdin())?
    } else {
        fs::read_to_string(&config.arquivo)
            .map_err(|e| format!("não consegui ler {}: {e}", config.arquivo))?
    };
    let ps = palavras(&texto);
    println!("linhas: {}", texto.lines().count());
    println!("palavras: {}", ps.len());
    println!("caracteres: {}", texto.chars().count());
    println!("mais frequentes:");
    for (p, n) in ranking(&ps, config.minimo).iter().take(config.top) {
        println!("{n:>4}  {p}");
    }
    Ok(())
}

#[cfg(test)]
mod tests {
    use super::*;

    fn s(v: &[&str]) -> Vec<String> {
        v.iter().map(|x| x.to_string()).collect()

    #[test]
    fn tira_pontuacao_e_maiusculas() {
        assert_eq!(palavras("O rio, o MAR."), s(&["o", "rio", "o", "mar"]));

    fn ranking_ordena_por_frequencia_e_nome() {

use std::{env, process};

use resumo::Config;

fn main() {
    let args: Vec<String> = env::args().collect();
    let config = Config::new(&args).unwrap_or_else(|erro| {
        eprintln!("erro: {erro}");
        eprintln!("uso: resumo <arquivo|-> [quantas palavras]");
        process::exit(1);
    });
    if let Err(e) = resumo::executar(config) {
        eprintln!("erro: {e}");
        process::exit(1);
    }
}

Passo 5: os testes

Os testes de unidade ficam no fim do lib.rs (já estão no arquivo acima, no módulo tests). O comentário /// de palavras tem um exemplo de código: o cargo test também o compila e roda, é o doc-test. Por fim, um teste de integração em tests/ roda o binário de verdade:

use std::process::Command;

#[test]
fn resume_o_poema() {
    let saida = Command::new(env!("CARGO_BIN_EXE_resumo"))
        .args(["poema.txt", "1"])
        .output()
        .unwrap();
    assert!(saida.status.success());
    let texto = String::from_utf8(saida.stdout).unwrap();
    assert!(texto.contains("linhas: 9"));
    assert!(texto.contains("   8  o"));
}

#[test]
fn arquivo_inexistente_sai_com_erro() {
    let saida = Command::new(env!("CARGO_BIN_EXE_resumo"))
        .arg("nao-existe.txt")
        .output()
        .unwrap();
    assert_eq!(saida.status.code(), Some(1));
    let erro = String::from_utf8(saida.stderr).unwrap();
    assert!(erro.contains("não consegui ler"));
}

env!("CARGO_BIN_EXE_resumo") é o caminho do executável que o cargo compilou para os testes. Command roda o programa como se fosse no terminal e captura saída e código de saída.

RESUMO_MIN=4 comando define a variável só para aquele comando: palavras curtas como “o”, “a” e “e” deixam de entrar no ranking. Com -, o texto vem do echo pelo | (pipe), e o resumo passa a funcionar como qualquer ferramenta de terminal.
