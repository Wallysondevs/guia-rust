Borrowing (referências)

Na aula passada, passar uma String para uma função fazia você perder a posse dela. A solução é emprestar: em vez do valor, você passa uma referência (&), que deixa a função usar o dado sem virar dona. Em Rust, isso se chama borrowing (empréstimo).

Você vai aprender
  • A criar referências com & e referências mutáveis com &mut.
  • A regra de ouro: várias leituras OU uma escrita, nunca as duas ao mesmo tempo.
  • Os erros E0596, E0499 e E0502, e por que o Rust não deixa uma referência ficar “pendurada”.

1. Emprestar para ler: &

fn tamanho(s: &String) -> usize {
    s.len()
}

fn main() {
    let texto = String::from("emprestado");
    let n = tamanho(&texto);
    println!("'{texto}' tem {n} letras");
}
$ cargo run
   Compiling ref v0.1.0 (/home/ana/projetos/ref)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.15s
     Running `target/debug/ref`
'emprestado' tem 10 letras

O &texto cria uma referência; a função recebe &String. Quando ela termina, só a referência some: o dono continua sendo texto, que segue válido no println!.

&texto
“empresta o texto para leitura”.
s: &String
o parâmetro é uma referência, não o dono.
s.len()
dá para ler pela referência normalmente.

fn adicionar(s: &String) {
    s.push_str(" mundo");
}

    adicionar(&texto);
    println!("{texto}");
}

fn adicionar(s: &mut String) {
    s.push_str(" mundo");
}

fn main() {

    adicionar(&mut texto);
    println!("{texto}");
}

Três lugares precisam concordar: a variável é mut, o empréstimo é &mut texto e o parâmetro é &mut String.

4. A regra: várias leituras OU uma escrita

Num mesmo momento, você pode ter quantas referências & quiser ou uma única &mut. Duas escritas ao mesmo tempo não pode:

fn main() {
    let mut s = String::from("a");
    let r1 = &mut s;
    let r2 = &mut s;
    r1.push('b');
    r2.push('c');
    println!("{s}");
}
$ cargo run
   Compiling dois-mut v0.1.0 (/home/ana/projetos/dois-mut)
error[E0499]: cannot borrow `s` as mutable more than once at a time
 --> src/main.rs:4:14
  |
3 |     let r1 = &mut s;
  |              ------ first mutable borrow occurs here
4 |     let r2 = &mut s;
  |              ^^^^^^ second mutable borrow occurs here
5 |     r1.push('b');
  |     -- first borrow later used here

For more information about this error, try `rustc --explain E0499`.
error: could not compile `dois-mut` (bin "dois-mut") due to 1 previous error

Erro E0499. E ler enquanto alguém escreve também não:

fn main() {
    let mut notas = vec![7, 8];
    let primeira = &notas[0];
    notas.push(10);
    println!("primeira: {primeira}");
}
$ cargo run
   Compiling ler-escrever v0.1.0 (/home/ana/projetos/ler-escrever)
error[E0502]: cannot borrow `notas` as mutable because it is also borrowed as immutable
 --> src/main.rs:4:5
  |
3 |     let primeira = &notas[0];
  |                     ----- immutable borrow occurs here
4 |     notas.push(10);
  |     ^^^^^^^^^^^^^^ mutable borrow occurs here
5 |     println!("primeira: {primeira}");
  |                          -------- immutable borrow later used here

For more information about this error, try `rustc --explain E0502`.
error: could not compile `ler-escrever` (bin "ler-escrever") due to 1 previous error

Erro E0502. Este é um bug real que o Rust evita: o push pode precisar de mais espaço e mudar o vetor de lugar na memória. Aí primeira apontaria para memória velha. Em C++, isso compila e dá problema na hora de rodar.

5. O empréstimo acaba no último uso

Um empréstimo dura só até a última vez que a referência é usada (não até o fim do bloco). Por isso, este código compila:

fn main() {
    let mut s = String::from("Rust");
    let r1 = &s;
    let r2 = &s;
    println!("{r1} e {r2}");
    // r1 e r2 não são mais usadas daqui para baixo
    let r3 = &mut s;
    r3.push_str("acean");
    println!("{r3}");
}
$ cargo run

     Running `target/debug/nll`

6. Não existe referência pendurada

Uma referência nunca pode viver mais que o dono. Tentar devolver uma referência para uma variável local é barrado:

fn criar() -> &String {
    let s = String::from("temporária");
    &s
}

fn main() {
    let r = criar();
    println!("{r}");
}
$ cargo run
   Compiling pendurada v0.1.0 (/home/ana/projetos/pendurada)
error[E0106]: missing lifetime specifier
 --> src/main.rs:1:15
  |
1 | fn criar() -> &String {
  |               ^ expected named lifetime parameter
  |
  = help: this function's return type contains a borrowed value, but there is no value for it to be borrowed from
help: consider using the `'static` lifetime, but this is uncommon unless you're returning a borrowed value from a `const` or a `static`
  |
1 | fn criar() -> &'static String {
  |                +++++++
help: instead, you are more likely to want to return an owned value
  |
1 - fn criar() -> &String {
1 + fn criar() -> String {
  |

For more information about this error, try `rustc --explain E0106`.
error: could not compile `pendurada` (bin "pendurada") due to 1 previous error

O s morre no fim de criar; a referência apontaria para memória liberada. O compilador pede um lifetime (assunto do Nível 2) e, na prática, a correção é devolver a própria String (a posse), não uma referência.

Resumo

  • &valor empresta para leitura; &mut valor, para escrita (a variável precisa ser mut).
  • Várias & ou uma &mut ao mesmo tempo (E0499, E0502).
  • O empréstimo termina no último uso da referência.
  • Uma referência nunca vive mais que o dono: nada de referência pendurada.
