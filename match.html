match e if let

O match compara um valor com uma lista de padrões e executa o braço do primeiro que encaixar. Parece um switch, mas é bem mais forte: ele desmonta enums, tuplas e structs, aceita faixas e condições e, principalmente, o compilador confere se você cobriu todos os casos.

Você vai aprender
  • A sintaxe do match e o erro E0004 quando falta um caso.
  • Padrões: curinga _, |, faixas a..=b, guardas if e desestruturação.
  • Os atalhos if let, while let e let … else.

1. O básico

fn nome_do_dia(n: u8) -> &'static str {
    match n {
        1 => "domingo",
        2 => "segunda",
        3 => "terça",
        4 => "quarta",
        5 => "quinta",
        6 => "sexta",
        7 => "sábado",
        _ => "dia inválido",
    }
}

fn main() {
    println!("{}", nome_do_dia(1));
    println!("{}", nome_do_dia(6));
    println!("{}", nome_do_dia(9));
}

o valor que vai ser comparado.

O match é uma expressão: o valor do braço escolhido vira o valor do match inteiro.

Erro E0004, non-exhaustive patterns: o match precisa ser exaustivo. O compilador diz qual variante falta (Oeste) e sugere o braço. Isso é ótimo quando você acrescenta uma variante a um enum: todo match que esqueceu dela vira erro de compilação, em vez de bug escondido.

3. Padrões: |, faixas e guardas

fn classificar(n: i32) -> &'static str {
    match n {
        0 => "zero",
        1 | 2 | 3 => "pequeno",
        4..=9 => "médio",
        x if x < 0 => "negativo",
        x if x % 2 == 0 => "grande e par",
        _ => "grande e ímpar",
    }
}

fn main() {
    for n in [0, 2, 7, -5, 40, 41] {
        println!("{n}: {}", classificar(n));
    }
}

O | junta padrões; 4..=9 é uma faixa; x if … dá um nome ao valor e acrescenta uma guarda (condição extra). Os braços são testados de cima para baixo.

4. Desestruturando tuplas, structs e enums

struct Ponto {
    x: i32,
    y: i32,
}

fn onde(p: &Ponto) -> String {
    match p {
        Ponto { x: 0, y: 0 } => String::from("na origem"),
        Ponto { x: 0, y } => format!("no eixo y, em {y}"),
        Ponto { x, y: 0 } => format!("no eixo x, em {x}"),
        Ponto { x, y } => format!("em ({x}, {y})"),
    }
}

fn main() {
    println!("{}", onde(&Ponto { x: 0, y: 0 }));
    println!("{}", onde(&Ponto { x: 0, y: 7 }));
    println!("{}", onde(&Ponto { x: 3, y: 4 }));
    let par = (true, 10);
    match par {
        (true, n) => println!("ligado com {n}"),
        (false, _) => println!("desligado"),
    }
}

5. if let: quando só um caso interessa

fn main() {
    let configuracao: Option<u32> = Some(8080);
    if let Some(porta) = configuracao {
        println!("usando a porta {porta}");
    }
    let vazio: Option<u32> = None;
    if let Some(p) = vazio {
        println!("porta {p}");

6. while let e let … else

fn ler_numero(texto: &str) -> u32 {
    let Ok(n) = texto.parse::<u32>() else {
        println!("'{texto}' não é número; usando 0");
        return 0;
    };
    n
}

fn main() {
    let mut pilha = vec![1, 2, 3];
    while let Some(topo) = pilha.pop() {
        println!("tirei {topo}");
    }
    println!("{}", ler_numero("42"));
    println!("{}", ler_numero("abc"));
}
$ cargo run

O while let repete enquanto o padrão encaixar (o pop devolve None quando a pilha esvazia). O let … else desmonta o valor ou, se não encaixar, executa o else, que precisa sair da função (return, break…).

Resumo

  • match testa padrões de cima para baixo e é uma expressão.
  • Ele precisa cobrir todos os casos (E0004); _ é o curinga.
  • Padrões: literais, |, faixas a..=b, guardas if e desestruturação.
  • if let, while let e let … else são atalhos para um padrão só.
