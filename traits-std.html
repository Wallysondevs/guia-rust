Traits da biblioteca padrão

Muita coisa “mágica” do Rust é só um trait da biblioteca padrão: {} no println! usa Display, + usa Add, for usa Iterator, o ? usa From. Implementando esses traits, seus tipos passam a funcionar com todas essas ferramentas.

1. Display: como o tipo aparece com {}

use std::fmt;

#[derive(Debug)]
struct Dinheiro {
    centavos: i64,
}

impl fmt::Display for Dinheiro {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "R$ {},{:02}", self.centavos / 100, self.centavos % 100)
    }
}

fn main() {
    let preco = Dinheiro { centavos: 1999 };
    println!("{}", preco);
    println!("{:?}", preco);
    let texto = preco.to_string();
    println!("texto com {} caracteres", texto.chars().count());
}
$ cargo run
   Compiling display v0.1.0 (/home/ana/projetos/display)

     Running `target/debug/display`

Debug (com derive) é para programadores; Display é para usuários e precisa ser escrito à mão. Ganho extra: quem implementa Display ganha .to_string() de graça.

2. Default

#[derive(Debug, Default)]
struct Config {
    porta: u16,
    detalhado: bool,
    nome: String,
}

#[derive(Debug)]
struct Janela {
    largura: u32,
    altura: u32,
}

impl Default for Janela {
    fn default() -> Self {
        Janela { largura: 800, altura: 600 }
    }
}

fn main() {
    println!("{:?}", Config::default());
    let c = Config { porta: 8080, ..Default::default() };
    println!("{:?}", c);
    if !c.detalhado && c.nome.is_empty() {
        println!("porta {} sem nome e sem detalhes", c.porta);
    }
    let j = Janela::default();
    println!("{:?} tem {} pixels", j, j.largura * j.altura);
}

O derive(Default) usa o padrão de cada campo (0, false, texto vazio). ..Default::default() preenche “o resto” dos campos.

3. From e Into: conversões

#[derive(Debug)]
struct Celsius(f64);

#[derive(Debug)]
struct Fahrenheit(f64);

impl From<Celsius> for Fahrenheit {
    fn from(c: Celsius) -> Self {
        Fahrenheit(c.0 * 9.0 / 5.0 + 32.0)
    }
}

fn main() {
    let f = Fahrenheit::from(Celsius(100.0));
    println!("{:?}", f);

    let g: Fahrenheit = Celsius(37.0).into();
    println!("{:.1} °F", g.0);

    let s: String = "texto".into();
    let n: i64 = 42i32.into();
    println!("{s} {n}");
}

TryFrom: conversão que pode falhar

use std::convert::TryFrom;

#[derive(Debug)]
struct Nota(u8);

impl TryFrom<i32> for Nota {
    type Error = String;
    fn try_from(v: i32) -> Result<Self, Self::Error> {
        if (0..=10).contains(&v) {
            Ok(Nota(v as u8))
        } else {
            Err(format!("{v} não é uma nota de 0 a 10"))
        }
    }
}

fn main() {
    println!("{:?}", Nota::try_from(8));
    println!("{:?}", Nota::try_from(15));
    let r: Result<Nota, _> = 7.try_into();
    if let Ok(nota) = r {
        println!("nota válida: {}", nota.0);
    }
    println!("{:?}", u8::try_from(300));
}

4. Sobrecarga de operadores

use std::ops::{Add, Mul, Neg};

#[derive(Debug, Clone, Copy, PartialEq)]
struct Vetor {
    x: f64,
    y: f64,
}

impl Add for Vetor {
    type Output = Vetor;
    fn add(self, outro: Vetor) -> Vetor {
        Vetor { x: self.x + outro.x, y: self.y + outro.y }
    }
}

impl Mul<f64> for Vetor {
    type Output = Vetor;
    fn mul(self, k: f64) -> Vetor {
        Vetor { x: self.x * k, y: self.y * k }
    }
}

impl Neg for Vetor {
    type Output = Vetor;
    fn neg(self) -> Vetor {
        Vetor { x: -self.x, y: -self.y }
    }
}

fn main() {
    let a = Vetor { x: 1.0, y: 2.0 };
    let b = Vetor { x: 3.0, y: -1.0 };
    println!("a + b = {:?}", a + b);
    println!("a * 3 = {:?}", a * 3.0);
    println!("-b    = {:?}", -b);
    println!("a + b == b + a? {}", a + b == b + a);
}

Cada operador é um trait de std::ops: Add (+), Sub (−), Mul (*), Div (/), Neg (− na frente), AddAssign (+=), Index ([]). O == vem de PartialEq.

5. Ordenando seus tipos: PartialOrd e Ord

use std::cmp::Ordering;

#[derive(Debug, PartialEq, Eq, PartialOrd, Ord)]
struct Versao(u32, u32, u32);

#[derive(Debug, PartialEq, Eq)]
struct Tarefa {
    nome: &'static str,
    prioridade: u8,
}

impl Ord for Tarefa {
    fn cmp(&self, outra: &Self) -> Ordering {
        outra.prioridade.cmp(&self.prioridade).then(self.nome.cmp(outra.nome))
    }
}

impl PartialOrd for Tarefa {
    fn partial_cmp(&self, outra: &Self) -> Option<Ordering> {
        Some(self.cmp(outra))
    }
}

fn main() {
    let mut versoes = vec![Versao(1, 10, 0), Versao(1, 2, 3), Versao(0, 9, 9)];
    versoes.sort();
    println!("{:?}", versoes);
    println!("1.2.3 < 1.10.0? {}", Versao(1, 2, 3) < Versao(1, 10, 0));

    let mut tarefas = vec![
        Tarefa { nome: "lavar louça", prioridade: 1 },
        Tarefa { nome: "pagar conta", prioridade: 5 },
        Tarefa { nome: "estudar Rust", prioridade: 5 },
    ];
    tarefas.sort();
    for t in &tarefas {
        println!("{} ({})", t.nome, t.prioridade);
    }
}

6. Iterator para seus tipos

struct Fibonacci {
    atual: u64,
    proximo: u64,
}

impl Iterator for Fibonacci {
    type Item = u64;
    fn next(&mut self) -> Option<u64> {
        let v = self.atual;
        self.atual = self.proximo;
        self.proximo += v;
        Some(v)
    }
}

fn fibonacci() -> Fibonacci {
    Fibonacci { atual: 0, proximo: 1 }
}

fn main() {
    let primeiros: Vec<u64> = fibonacci().take(10).collect();
    println!("{:?}", primeiros);
    let soma_pares: u64 = fibonacci().take_while(|&n| n < 1000).filter(|n| n % 2 == 0).sum();
    println!("soma dos pares abaixo de 1000: {soma_pares}");
}

Missão: Implemente Iterator para Contagem: cada next devolve o valor atual e diminui 1, e devolve None quando chegar a zero. A saída deve ser [3, 2, 1].

struct Contagem {
    n: u32,
}

fn main() {
    let c = Contagem { n: 3 };
    let v: Vec<u32> = vec![c.n];
    println!("{:?}", v);

struct Contagem {
    n: u32,
}

impl Iterator for Contagem {
    type Item = u32;
    fn next(&mut self) -> Option<u32> {
        if self.n == 0 {
            None
        } else {
            self.n -= 1;
            Some(self.n + 1)
        }
    }
}

fn main() {
    let c = Contagem { n: 3 };
    let v: Vec<u32> = c.collect();
    println!("{:?}", v);
}

Resumo

  • Display define o {} e dá to_string(); Debug define o {:?}.
  • Default dá valores iniciais; ..Default::default() completa structs.
  • From dá Into de graça; TryFrom para conversões que podem falhar.
  • Operadores são traits de std::ops; Ord define a ordem do sort; Iterator só exige next.
