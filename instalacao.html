Instalando o Rust (rustup)

O jeito oficial de instalar o Rust é o rustup, um pequeno programa que baixa o compilador, o cargo e a biblioteca padrão, e depois cuida das atualizações. Ele instala tudo na sua pasta de usuário, sem precisar de administrador.

Você vai aprender
  • A instalar o Rust no Linux e no macOS com uma linha, e no Windows com o instalador.
  • A conferir se deu certo com rustc --version e cargo --version.
  • A atualizar com rustup update e a ver o que está instalado com rustup show.
Sobre as saídas. As saídas desta aula foram colhidas num Linux, com a usuária ana. No seu computador, as datas e números de versão podem ser mais novos.

1. Linux e macOS: uma linha no terminal

Abra o terminal e cole o comando do site oficial (rustup.rs). Ele baixa o instalador e o executa. Na coleta usamos -y (aceitar as opções padrão sem perguntar) e o perfil minimal (só o essencial). Sem essas opções, o instalador mostra um menu: aperte Enter para a instalação padrão.

$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --profile minimal
info: profile set to minimal
info: default host tuple is x86_64-unknown-linux-gnu
info: syncing channel updates for stable-x86_64-unknown-linux-gnu
info: latest update on 2026-11-12 for version 1.100.0 (0ef1bc386 2026-11-09)
info: downloading 3 components
info: default toolchain set to stable-x86_64-unknown-linux-gnu

  stable-x86_64-unknown-linux-gnu installed - rustc 1.100.0 (0ef1bc386 2026-11-09)

Este é um trecho da saída real: cortamos as primeiras linhas, que só falavam de outra cópia do Rust que já existia naquela máquina. O recado do fim é importante: os programas ficam em ~/.cargo/bin, e o terminal que já estava aberto ainda não sabe disso. Feche e abra o terminal de novo, ou rode a linha com o ponto:

. "$HOME/.cargo/env"

No Linux, falta um linker?

O Rust usa o linker do sistema para montar o executável final. Se o primeiro cargo run reclamar de linker `cc` not found, instale as ferramentas de compilação: no Ubuntu e no Debian, sudo apt install build-essential.

2. Windows

No Windows, baixe o rustup-init.exe em rustup.rs e execute. O instalador pede as Build Tools do Visual Studio (o linker da Microsoft) e se oferece para instalá-las. Aceite, espere terminar e abra um terminal novo. Os comandos das próximas seções são os mesmos no Windows.

3. Conferindo a instalação

Três comandos, três versões. Se algum responder command not found, o ~/.cargo/bin ainda não está no PATH: abra outro terminal.

$ rustc --version
rustc 1.100.0 (0ef1bc386 2026-11-09)
$ cargo --version
cargo 1.100.0 (3acc79c0c 2026-11-05)
$ rustup --version
rustup 1.29.3 (edbc831ce 2026-11-02)
info: This is the version for the rustup toolchain manager, not the rustc compiler.
info: the currently active `rustc` version is `rustc 1.100.0 (0ef1bc386 2026-11-09)`

O rustup --version lembra que ele é o gerenciador, não o compilador, e diz qual rustc está ativo. O número entre parênteses é o código da versão e a data em que ela foi gerada.

4. O que está instalado: rustup show

$ rustup show
Default host: x86_64-unknown-linux-gnu
rustup home:  /home/ana/.rustup

installed toolchains
--------------------
stable-x86_64-unknown-linux-gnu (active, default)

active toolchain
----------------
name: stable-x86_64-unknown-linux-gnu
active because: it's the default toolchain
installed targets:
  x86_64-unknown-linux-gnu

Um toolchain é um conjunto completo (compilador, cargo e biblioteca padrão) de uma versão. O stable é a versão estável, lançada a cada seis semanas. Existem também o beta e o nightly (a de todo dia, com recursos experimentais). Neste guia, só o stable.

Você digitaO que faz
rustup updateAtualiza os toolchains instalados para a versão mais nova.
rustup showMostra o que está instalado e qual toolchain está ativo.
rustup docAbre a documentação oficial no navegador, sem internet.
rustup self uninstallRemove o Rust e o rustup do seu usuário.

5. Onde ficam os arquivos

  • ~/.rustup: os toolchains (compiladores, bibliotecas).
  • ~/.cargo/bin: os executáveis rustc, cargo, rustup e os programas que você instalar com cargo install.

Resumo

  • Instale com o rustup (uma linha no Linux/macOS, rustup-init.exe no Windows).
  • Confira com rustc --version e cargo --version; abra um terminal novo se não achar os comandos.
  • rustup update atualiza; rustup show mostra o que está instalado.
