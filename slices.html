Slices (&str e &[T])

Um slice (fatia) é uma referência para um pedaço de uma sequência: parte de um texto, parte de um array ou de um vetor. Ele não copia nada, só aponta para o começo e guarda o tamanho. É o jeito do Rust de dizer “estes elementos, daqui até ali”.

Você vai aprender
  • A fatiar textos (&s[0..5]) e arrays (&a[1..3]).
  • A diferença entre String (dona do texto) e &str (fatia emprestada).
  • Por que &str é o melhor tipo de parâmetro e o cuidado com acentos ao fatiar.

1. Fatias de texto

fn main() {
    let frase = String::from("olá mundo");
    let mundo = &frase[5..];
    let ola = &frase[..4];
    println!("[{ola}] [{mundo}]");
    println!("bytes: {}", frase.len());
}

Os números são posições em bytes, não em letras. O á ocupa 2 bytes em UTF-8, por isso “olá” vai de 0 a 4 e a frase tem 10 bytes, não 9. As faixas funcionam como no for: [a..b], [..b] (do começo), [a..] (até o fim), [..] (tudo).

Panic: o byte 3 cai no meio do á. O Rust não deixa um &str conter UTF-8 inválido. Para trabalhar por letra, use .chars():

fn main() {
    let frase = "olá mundo";
    let tres: String = frase.chars().take(3).collect();
    println!("{tres}");
    println!("letras: {}", frase.chars().count());

Um literal como "oi" já é um &str: uma fatia do texto que fica gravado dentro do executável. Por isso a regra prática: receba &str nos parâmetros. Uma &String vira &str sozinha, então a função aceita os dois:

fn primeira_palavra(s: &str) -> &str {
    for (i, c) in s.char_indices() {
        if c == ' ' {
            return &s[..i];
        }
    }
    s
}

fn main() {
    let dona = String::from("bom dia");
    println!("{}", primeira_palavra(&dona));
    println!("{}", primeira_palavra("Rust é legal"));
    println!("{}", primeira_palavra("sozinha"));
}

4. Slices protegem contra dados velhos

Como o slice é um empréstimo, o compilador não deixa o texto original mudar enquanto a fatia é usada:

fn main() {
    let mut s = String::from("bom dia");
    let palavra = &s[..3];
    s.clear();
    println!("{palavra}");
}
$ cargo run
   Compiling slice-clear v0.1.0 (/home/ana/projetos/slice-clear)
error[E0502]: cannot borrow `s` as mutable because it is also borrowed as immutable
 --> src/main.rs:4:5
  |
3 |     let palavra = &s[..3];
  |                    - immutable borrow occurs here
4 |     s.clear();
  |     ^^^^^^^^^ mutable borrow occurs here
5 |     println!("{palavra}");
  |                ------- immutable borrow later used here

For more information about this error, try `rustc --explain E0502`.
error: could not compile `slice-clear` (bin "slice-clear") due to 1 previous error

O clear precisa de &mut s, mas palavra ainda empresta s para leitura: erro E0502, o mesmo da aula anterior. Sem essa regra, palavra apontaria para um texto apagado.

5. Fatias de arrays e vetores: &[T]

fn soma(valores: &[i32]) -> i32 {
    let mut total = 0;
    for v in valores {
        total += v;
    }
    total
}

fn main() {
    let a = [1, 2, 3, 4, 5];
    let meio = &a[1..4];
    println!("{:?}", meio);
    println!("soma de tudo: {}", soma(&a));
    println!("soma do meio: {}", soma(meio));
    let v = vec![10, 20, 30];
    println!("soma do vetor: {}", soma(&v));
}
$ cargo run

Assim como &str serve para String e literais, &[i32] serve para arrays, vetores e pedaços deles.

Missão: Escreva fn maior(v: &[i32]) -> i32, que devolve o maior número da fatia. Teste com o vetor vec![3, 42, 7, 15] e imprima Maior: 42.

fn main() {
    let v = vec![3, 42, 7, 15];
}

fn maior(v: &[i32]) -> i32 {
    let mut m = v[0];
    for &x in v {
        if x > m {
            m = x;
        }
    }
    m
}

Resumo

  • Slice = referência para um pedaço: &s[a..b], &v[a..].
  • Em texto, as posições são bytes; fatiar no meio de um caractere dá panic. Use .chars() para letras.
  • String é dona; &str é fatia. Prefira &str e &[T] nos parâmetros.
