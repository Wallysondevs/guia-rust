HashMap

Um HashMap<K, V> guarda pares chave → valor, como uma agenda (nome → telefone) ou um placar (time → pontos). Você procura pelo nome da chave, não pela posição. Ele mora em std::collections, então precisa de um use.

Você vai aprender
  • A inserir, ler, atualizar e remover pares.
  • A API entry, perfeita para contar ou agrupar.
  • Quando usar BTreeMap (ordenado) e HashSet (só chaves).

1. O básico

use std::collections::HashMap;

fn main() {
    let mut estoque: HashMap<String, u32> = HashMap::new();
    estoque.insert(String::from("caneta"), 40);
    estoque.insert(String::from("caderno"), 12);
    estoque.insert(String::from("caneta"), 35);

    println!("canetas: {:?}", estoque.get("caneta"));
    println!("borrachas: {:?}", estoque.get("borracha"));
    println!("tem caderno? {}", estoque.contains_key("caderno"));
    println!("itens: {}", estoque.len());
    if let Some(qtd) = estoque.remove("caderno") {
        println!("removi {qtd} cadernos");
    }
    println!("{:?}", estoque);
}

2. Percorrendo: a ordem não é garantida

use std::collections::HashMap;

fn main() {
    let mut placar = HashMap::new();
    placar.insert("Azul", 3);
    placar.insert("Vermelho", 5);
    placar.insert("Verde", 1);
    let mut times: Vec<_> = placar.iter().collect();
    times.sort_by(|a, b| b.1.cmp(a.1));
    for (time, pontos) in times {
        println!("{time}: {pontos}");
    }
}
$ cargo run

O HashMap não guarda os pares em ordem nenhuma (e a ordem pode mudar a cada execução). Para mostrar ordenado, copie os pares para um vetor e ordene, como acima, ou use um BTreeMap.

3. entry: inserir ou atualizar

use std::collections::BTreeMap;

fn main() {
    let texto = "o sol e o mar e o céu";
    let mut contagem = BTreeMap::new();
    for palavra in texto.split_whitespace() {
        let n = contagem.entry(palavra).or_insert(0);
        *n += 1;
    }
    println!("{:?}", contagem);
}
$ cargo run
   Compiling entry v0.1.0 (/home/ana/projetos/entry)

     Running `target/debug/entry`
{"céu": 1, "e": 2, "mar": 1, "o": 3, "sol": 1}

entry(chave).or_insert(0) devolve uma referência mutável ao valor: o que já existia ou um 0 recém-inserido. O *n += 1 soma por essa referência. O BTreeMap tem a mesma interface do HashMap, mas mantém as chaves ordenadas, por isso a saída sai em ordem alfabética.

5. HashSet: só as chaves

use std::collections::HashSet;

fn main() {
    let visitas = ["Ana", "Bia", "Ana", "Caio", "Bia"];
    let unicos: HashSet<&str> = visitas.iter().cloned().collect();
    println!("{} visitantes diferentes", unicos.len());
    println!("Caio veio? {}", unicos.contains("Caio"));
    let a: HashSet<i32> = [1, 2, 3].into_iter().collect();
    let b: HashSet<i32> = [2, 3, 4].into_iter().collect();
    let mut comuns: Vec<_> = a.intersection(&b).collect();
    comuns.sort();
    println!("em comum: {:?}", comuns);
}

Resumo

  • use std::collections::HashMap;; insert, get (Option), remove, contains_key.
  • entry(k).or_insert(v) insere ou devolve o valor existente, ótimo para contar.
  • O HashMap não tem ordem; BTreeMap tem. HashSet guarda valores únicos.
  • insert recebe a posse da chave e do valor.
