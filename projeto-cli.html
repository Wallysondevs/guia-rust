Projeto final: CLI (parte 1)

Hora de juntar tudo. Nestas duas aulas você vai construir resumo, uma ferramenta de terminal de verdade: ela lê um arquivo de texto e mostra quantas linhas, palavras e caracteres ele tem, e quais palavras aparecem mais. Nesta parte: argumentos, erros e a lógica. Na parte 2: biblioteca, testes, variáveis de ambiente, entrada padrão e versão de release.

O que você vai usar: cargo, String e slices, struct e impl, Result e ?, Box<dyn Error>, closures, iteradores e HashMap. Se algum desses estiver nebuloso, a aula correspondente está no menu.

No fim desta aula, cargo run -q -- poema.txt 3 vai mostrar a contagem e as 3 palavras mais frequentes do arquivo.

Passo 1: lendo os argumentos

std::env::args() devolve um iterador com os argumentos da linha de comando. O primeiro é sempre o caminho do próprio programa.

use std::env;

fn main() {
    let args: Vec<String> = env::args().collect();
    println!("{:?}", args);
}
$ cargo run -q -- poema.txt 3
["target/debug/resumo", "poema.txt", "3"]
$ cargo run -q
["target/debug/resumo"]

Tudo que vem depois de -- vai para o seu programa, não para o cargo. O -q (quiet) esconde as linhas Compiling/Running do cargo.

Passo 2: Config e mensagens de erro

Em vez de espalhar args[1] pelo código, junte a configuração numa struct, com um construtor que devolve Result:

use std::env;
use std::process;

struct Config {
    arquivo: String,
    top: usize,
}

impl Config {
    fn new(args: &[String]) -> Result<Config, String> {
        if args.len() < 2 {
            return Err("faltou o nome do arquivo".to_string());
        }
        let arquivo = args[1].clone();
        let top = match args.get(2) {
            Some(t) => t.parse().map_err(|_| format!("'{t}' não é um número"))?,
            None => 5,
        };
        Ok(Config { arquivo, top })
    }
}

fn main() {
    let args: Vec<String> = env::args().collect();
    let config = Config::new(&args).unwrap_or_else(|erro| {
        eprintln!("erro: {erro}");
        eprintln!("uso: resumo <arquivo> [quantas palavras]");
        process::exit(1);
    });
    println!("arquivo: {}, top: {}", config.arquivo, config.top);
}

arquivo: poema.txt, top: 5
$ cargo run -q -- poema.txt 3
arquivo: poema.txt, top: 3
$ cargo run -q -- poema.txt três
erro: 'três' não é um número
uso: resumo <arquivo> [quantas palavras]
$ echo "código de saída: $?"
código de saída: 1
$ cargo run -q
erro: faltou o nome do arquivo
uso: resumo <arquivo> [quantas palavras]
Config::new
valida os argumentos e devolve Ok(Config) ou Err(mensagem).
args.get(2)
devolve Option: o terceiro argumento é opcional, e o padrão é 5.
map_err(...)?
troca o erro do parse por uma mensagem nossa e devolve cedo.
unwrap_or_else
se der erro, roda a closure: mostra a mensagem e encerra.
eprintln!
escreve na saída de erro (stderr), não na saída normal. Assim, quem redireciona a saída para um arquivo continua vendo os erros na tela.
process::exit(1)
encerra com código 1. Por convenção, 0 é sucesso e qualquer outro número é falha; scripts usam isso (veja o $?).

Passo 3: ler o arquivo e contar

A lógica fica numa função executar que devolve Result<(), Box<dyn Error>>, para usar ? com qualquer tipo de erro.

use std::collections::HashMap;
use std::env;
use std::error::Error;
use std::fs;
use std::process;

struct Config {
    arquivo: String,
    top: usize,
}

impl Config {
    fn new(args: &[String]) -> Result<Config, String> {
        if args.len() < 2 {
            return Err("faltou o nome do arquivo".to_string());
        }
        let arquivo = args[1].clone();
        let top = match args.get(2) {
            Some(t) => t.parse().map_err(|_| format!("'{t}' não é um número"))?,
            None => 5,
        };
        Ok(Config { arquivo, top })
    }
}

fn executar(config: Config) -> Result<(), Box<dyn Error>> {
    let texto = fs::read_to_string(&config.arquivo)
        .map_err(|e| format!("não consegui ler {}: {e}", config.arquivo))?;

    let palavras: Vec<String> = texto
        .split_whitespace()
        .map(|p| p.trim_matches(|c: char| !c.is_alphanumeric()).to_lowercase())
        .filter(|p| !p.is_empty())
        .collect();

    println!("linhas: {}", texto.lines().count());
    println!("palavras: {}", palavras.len());
    println!("caracteres: {}", texto.chars().count());

    let mut contagem: HashMap<&str, usize> = HashMap::new();
    for p in &palavras {
        *contagem.entry(p.as_str()).or_insert(0) += 1;
    }
    let mut ranking: Vec<(&str, usize)> = contagem.into_iter().collect();
    ranking.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(b.0)));

    println!("mais frequentes:");
    for (p, n) in ranking.iter().take(config.top) {
        println!("{n:>4}  {p}");
    }
    Ok(())
}

fn main() {
    let args: Vec<String> = env::args().collect();
    let config = Config::new(&args).unwrap_or_else(|erro| {
        eprintln!("erro: {erro}");
        eprintln!("uso: resumo <arquivo> [quantas palavras]");
        process::exit(1);
    });
    if let Err(e) = executar(config) {
        eprintln!("erro: {e}");
        process::exit(1);
    }
}

linhas: 9
palavras: 49
caracteres: 213
mais frequentes:

   3  a
   3  chuva
$ cargo run -q -- poema.txt
linhas: 9
palavras: 49
caracteres: 213

erro: não consegui ler sumiu.txt: No such file or directory (os error 2)

Os pontos-chave:

  • trim_matches(|c: char| !c.is_alphanumeric()) tira pontuação das pontas ("mar," vira "mar") sem estragar letras acentuadas, porque is_alphanumeric entende Unicode.
  • entry(...).or_insert(0) cria o contador na primeira vez e soma depois (veja a aula de HashMap).
  • O HashMap não tem ordem, então o sort_by ordena por frequência (maior primeiro) e, no empate, em ordem alfabética: a saída sai igual em toda execução.
  • Uma String com a mensagem vira Box<dyn Error> sozinha no ?, graças ao From.
  • texto.chars().count() conta caracteres; texto.len() contaria bytes, e cada letra acentuada ocupa 2.

Estas missões usam argumentos: rode exatamente o comando indicado em cada uma.

Missão: Faça o programa somar todos os números passados na linha de comando (pule o primeiro argumento, que é o nome do programa). Rodando cargo run -- 10 20 12, a saída deve ser soma: 42.

    // some os números passados na linha de comando
    let soma = 0;
    println!("soma: {soma}");
}

use std::env;

fn main() {
    let soma: i32 = env::args()
        .skip(1)
        .map(|a| a.parse::<i32>().unwrap())
        .sum();

Resumo

  • env::args() lê os argumentos; cargo run -- ... repassa argumentos ao programa.
  • Uma struct Config com new() -> Result centraliza a validação.
  • Erros vão para o stderr com eprintln!, e process::exit(1) sinaliza falha.
  • executar() -> Result<(), Box<dyn Error>> deixa usar ? com qualquer erro.
