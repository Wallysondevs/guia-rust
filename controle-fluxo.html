Controle de fluxo

Controle de fluxo é decidir o que roda e quantas vezes. Rust tem if/else e três laços: loop (para sempre, até um break), while (enquanto a condição valer) e for (para cada item). Uma diferença para outras linguagens: if e loop são expressões e podem devolver valores.

Você vai aprender
  • if, else if, else e o if que devolve valor.
  • loop com break valor, rótulos 'externo:, while e for com faixas.
  • O erro real quando a condição não é bool.

1. if, else if, else

fn main() {
    let temperatura = 31;
    if temperatura > 30 {
        println!("calor");
    } else if temperatura > 18 {
        println!("agradável");
    } else {
        println!("frio");
    }
}

Não há parênteses em volta da condição, e as chaves são obrigatórias, mesmo com uma linha só.

2. Quando dá errado: condição que não é bool

fn main() {
    let itens = 3;
    if itens {
        println!("tem itens");
    }
}
$ cargo run
   Compiling if-erro v0.1.0 (/home/ana/projetos/if-erro)
error[E0308]: mismatched types
 --> src/main.rs:3:8
  |
3 |     if itens {
  |        ^^^^^ expected `bool`, found integer

For more information about this error, try `rustc --explain E0308`.
error: could not compile `if-erro` (bin "if-erro") due to 1 previous error

Em C e em JavaScript, um número diferente de zero conta como “verdadeiro”. Em Rust, não: a condição precisa ser bool. Escreva a comparação: if itens > 0.

3. if como expressão

fn main() {
    let idade = 17;
    let situacao = if idade >= 18 { "maior" } else { "menor" };
    println!("{situacao} de idade");
}
$ cargo run
   Compiling if-expr v0.1.0 (/home/ana/projetos/if-expr)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.09s
     Running `target/debug/if-expr`

Os dois braços precisam devolver o mesmo tipo. Se um devolver texto e o outro número, é erro E0308 (if and else have incompatible types).

4. loop e break com valor

fn main() {
    let mut contador = 0;
    let resultado = loop {
        contador += 1;
        if contador == 10 {
            break contador * 2;
        }
    };
    println!("resultado: {resultado}");
}
$ cargo run
   Compiling loop v0.1.0 (/home/ana/projetos/loop)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s
     Running `target/debug/loop`

O loop repete para sempre; o break sai e pode levar um valor junto. O continue pula para a próxima volta.

5. Rótulos: sair de dois laços de uma vez

fn main() {
    'externo: for i in 1..=3 {
        for j in 1..=3 {
            if i * j == 4 {

7. for e faixas

fn main() {
    for i in 0..3 {
        print!("{i} ");
    }
    println!();
    for i in 1..=3 {
        print!("{i} ");
    }
    println!();
    for i in (1..=3).rev() {
        print!("{i} ");
    }
    println!();
    let frutas = ["maçã", "uva", "kiwi"];
    for f in frutas {
        println!("fruta: {f}");
    }
    for (i, f) in frutas.iter().enumerate() {
        println!("{i}: {f}");
    }
}

O for é o laço mais usado em Rust: ele nunca erra o índice, porque não usa índice. O enumerate() entrega o par (posição, item) quando você precisa da posição.

    let nota = 8;
}

fn main() {
    let nota = 8;
    let conceito = if nota >= 9 { "A" } else if nota >= 7 { "B" } else { "C" };

Resumo

  • if sem parênteses, com chaves; a condição é sempre bool.
  • if e loop são expressões: let x = if … { } else { };, break valor.
  • while repete enquanto a condição vale; for x in coleção percorre itens.
  • Faixas: a..b (sem o fim), a..=b (com o fim), .rev().
