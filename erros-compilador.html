Erros comuns do compilador

Esta aula é uma coleção de “erros de propósito”: cada exemplo quebra uma regra, mostra a mensagem real do compilador e explica a correção. Guarde esta página para consultar quando um erro parecer misterioso.

Como ler uma mensagem do rustc
  1. error[E0382]: o código do erro. rustc --explain E0382 mostra uma explicação longa, com exemplos.
  2. A frase depois do código: o resumo do problema.
  3. --> src/main.rs:4:20: arquivo, linha e coluna.
  4. O desenho com ^^^ e ---: o lugar principal e os lugares relacionados, cada um com uma etiqueta.
  5. help: e note:: dicas, muitas vezes com o código já corrigido.

Erro de digitação. O compilador procura nomes parecidos e sugere o certo.

E0599: método que não existe para o tipo

fn main() {
    let v = vec![3, 1, 2];
    let n = v.size();
    println!("{n}");
}
$ cargo run
   Compiling e0599 v0.1.0 (/home/ana/projetos/e0599)
error[E0599]: no method named `size` found for struct `Vec<{integer}>` in the current scope
 --> src/main.rs:3:15
  |
3 |     let n = v.size();
  |               ^^^^
  |
help: you might have meant to use `len`
  |
3 -     let n = v.size();
3 +     let n = v.len();
  |

For more information about this error, try `rustc --explain E0599`.
error: could not compile `e0599` (bin "e0599") due to 1 previous error

Em Rust, o tamanho de um Vec é len(). A mensagem diz que não há size para Vec e sugere o nome parecido.

Tipos

E0308: tipos que não combinam

fn dobro(x: i32) -> i32 {
    x * 2
}

fn main() {
    let texto = "21";
    println!("{}", dobro(texto));
}
$ cargo run
   Compiling e0308 v0.1.0 (/home/ana/projetos/e0308)
error[E0308]: mismatched types
 --> src/main.rs:7:26
  |
7 |     println!("{}", dobro(texto));
  |                    ----- ^^^^^ expected `i32`, found `&str`
  |                    |
  |                    arguments to this function are incorrect
  |
note: function defined here
 --> src/main.rs:1:4
  |
1 | fn dobro(x: i32) -> i32 {
  |    ^^^^^ ------

For more information about this error, try `rustc --explain E0308`.
error: could not compile `e0308` (bin "e0308") due to 1 previous error

A função espera i32 e recebeu &str. Rust nunca converte texto em número sozinho: use texto.parse::<i32>().

E0277: falta um trait

fn main() {
    let notas = vec![7, 8, 9];
    println!("{}", notas);
}
$ cargo run
   Compiling e0277 v0.1.0 (/home/ana/projetos/e0277)
error[E0277]: `Vec<{integer}>` doesn't implement `std::fmt::Display`
 --> src/main.rs:3:20

  |               --   ^^^^^ `Vec<{integer}>` cannot be formatted with the default formatter
  |               |
  |               required by this formatting parameter
  |

O {} exige o trait Display, e o Vec não tem um jeito “bonito” padrão de aparecer. A note sugere o {:?}, que usa o Debug.

E0369: operador que o tipo não tem

struct Ponto {
    x: i32,
    y: i32,
}

fn main() {
    let a = Ponto { x: 1, y: 2 };
    let b = Ponto { x: 1, y: 2 };

}
$ cargo run
   Compiling e0369 v0.1.0 (/home/ana/projetos/e0369)

  |                    |
  |                    Ponto
  |

 --> src/main.rs:1:1
  |

  | ^^^^^^^^^^^^ must implement `PartialEq`

Ownership e borrowing

E0382: usar um valor depois de movê-lo

fn main() {
    let nomes = vec![String::from("Ana"), String::from("Bia")];
    for n in nomes {
        println!("{n}");
    }
    println!("{} nomes", nomes.len());
}
$ cargo run
   Compiling e0382 v0.1.0 (/home/ana/projetos/e0382)
error[E0382]: borrow of moved value: `nomes`
 --> src/main.rs:6:26
  |
2 |     let nomes = vec![String::from("Ana"), String::from("Bia")];
  |         ----- move occurs because `nomes` has type `Vec<String>`, which does not implement the `Copy` trait
3 |     for n in nomes {
  |              ----- `nomes` moved due to this implicit call to `.into_iter()`
...
6 |     println!("{} nomes", nomes.len());
  |                          ^^^^^ value borrowed here after move
  |
note: the `for` loop is desugared into a call to `std::iter::IntoIterator::into_iter`, which takes ownership of the receiver `self`, which moves `nomes`
 --> /rustc/0ef1bc386059596dada8fb65b50425aab2ea637a/library/core/src/iter/traits/collect.rs:312:17
help: consider iterating over a slice of the `Vec<String>`'s content to avoid moving into the `for` loop
  |
3 |     for n in &nomes {
  |              +

For more information about this error, try `rustc --explain E0382`.
error: could not compile `e0382` (bin "e0382") due to 1 previous error

O for n in nomes consome o vetor (chama into_iter). Para só percorrer, use for n in &nomes; o próprio compilador sugere isso.

E0716: referência para um valor temporário

fn main() {
    let palavra: &str = String::from("temporária").as_str();
    println!("{palavra}");
}
$ cargo run
   Compiling e0716 v0.1.0 (/home/ana/projetos/e0716)
error[E0716]: temporary value dropped while borrowed
 --> src/main.rs:2:25
  |
2 |     let palavra: &str = String::from("temporária").as_str();
  |                         ^^^^^^^^^^^^^^^^^^^^^^^^^^         - temporary value is freed at the end of this statement
  |                         |
  |                         creates a temporary value which is freed while still in use
3 |     println!("{palavra}");
  |                ------- borrow later used here
  |
help: consider using a `let` binding to create a longer lived value
  |
2 ~     let binding = String::from("temporária");
3 ~     let palavra: &str = binding.as_str();
  |

For more information about this error, try `rustc --explain E0716`.
error: could not compile `e0716` (bin "e0716") due to 1 previous error

A String criada na linha é temporária: morre no fim da instrução, e a referência ficaria pendurada. Guarde a String numa variável primeiro: let s = String::from("…"); let palavra = s.as_str();.

Resumo

  • Leia a mensagem inteira: código, frase, local, desenho e help.
  • rustc --explain EXXXX dá a explicação longa de qualquer erro.
  • Os mais comuns são de nomes (E0425, E0599), tipos (E0308, E0277) e ownership (E0382, E0499, E0502).
  • Warnings não impedem a compilação, mas merecem atenção; cargo clippy ajuda ainda mais.
