Métodos e impl

Um método é uma função que pertence a um tipo. Em vez de area(&retangulo), você escreve retangulo.area(). Em Rust, os métodos ficam num bloco impl, separado da definição da struct, e o primeiro parâmetro diz como o método usa a instância: lendo, mudando ou consumindo.

Você vai aprender
  • A escrever métodos com &self, &mut self e self.
  • Funções associadas, como o construtor new, chamadas com Tipo::funcao().
  • O que o compilador diz quando você chama um método que muda numa variável imutável.

1. O primeiro método: &self

struct Retangulo {
    largura: u32,
    altura: u32,
}

impl Retangulo {
    fn area(&self) -> u32 {
        self.largura * self.altura
    }

    fn cabe(&self, outro: &Retangulo) -> bool {
        self.largura >= outro.largura && self.altura >= outro.altura
    }
}

fn main() {
    let grande = Retangulo { largura: 30, altura: 50 };
    let pequeno = Retangulo { largura: 10, altura: 40 };
    println!("área: {}", grande.area());
    println!("o pequeno cabe no grande? {}", grande.cabe(&pequeno));
    println!("o grande cabe no pequeno? {}", pequeno.cabe(&grande));
}

2. Funções associadas: new

Uma função no impl sem self é uma função associada. A mais comum é o construtor new. Chama-se com ::, como o String::from que você já usa.

#[derive(Debug)]
struct Retangulo {
    largura: u32,
    altura: u32,
}

impl Retangulo {
    fn new(largura: u32, altura: u32) -> Self {
        Self { largura, altura }
    }

    fn quadrado(lado: u32) -> Self {
        Self { largura: lado, altura: lado }
    }
}

fn main() {
    let r = Retangulo::new(3, 4);
    let q = Retangulo::quadrado(5);
    println!("{:?}\n{:?}", r, q);
    println!("áreas: {} e {}", r.largura * r.altura, q.largura * q.altura);
}

Dentro do impl, Self (com maiúscula) é um apelido para o próprio tipo.

3. Métodos que mudam: &mut self

struct Contador {
    valor: u32,
}

impl Contador {
    fn new() -> Self {
        Contador { valor: 0 }
    }
    fn incrementar(&mut self) {
        self.valor += 1;
    }
    fn zerar(&mut self) {
        self.valor = 0;
    }
}

fn main() {
    let mut c = Contador::new();
    c.incrementar();
    c.incrementar();
    c.incrementar();
    println!("valor: {}", c.valor);
    c.zerar();
    println!("depois de zerar: {}", c.valor);
}

4. Quando dá errado: método &mut em variável imutável

struct Contador {
    valor: u32,
}

impl Contador {
    fn incrementar(&mut self) {
        self.valor += 1;
    }
}

fn main() {
    let c = Contador { valor: 0 };
    c.incrementar();
    println!("{}", c.valor);
}

O método pede &mut self, então a variável precisa ser mut. A mensagem (E0596) mostra a correção: let mut c.

5. Métodos que consomem: self

Com self (sem &), o método recebe a posse da instância. Depois da chamada, a variável não pode mais ser usada. Serve para transformar um valor em outro:

struct Pedido {
    itens: Vec<String>,
}

impl Pedido {
    fn finalizar(self) -> String {
        format!("pedido com {} itens: {}", self.itens.len(), self.itens.join(", "))
    }
}

fn main() {
    let p = Pedido { itens: vec![String::from("café"), String::from("bolo")] };
    let recibo = p.finalizar();
    println!("{recibo}");
}

Resumo

  • Métodos ficam em impl Tipo { … } e são chamados com ponto.
  • &self lê, &mut self muda, self consome.
  • Funções sem self são associadas: Tipo::new(). Self é o próprio tipo.
