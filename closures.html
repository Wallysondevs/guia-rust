Closures

Uma closure é uma função sem nome que você escreve no meio do código e guarda numa variável ou passa para outra função. Ela pode usar as variáveis do lugar onde foi criada: isso se chama capturar o ambiente. Você já viu closures em unwrap_or_else(|| …) e retain(|x| …).

Você vai aprender
  • A sintaxe |parâmetros| expressão e a inferência de tipos.
  • Como a closure captura variáveis (por referência, por referência mutável ou com move).
  • Os traits Fn, FnMut e FnOnce, e funções que recebem ou devolvem closures.

1. A sintaxe

fn main() {
    let dobro = |x| x * 2;
    let soma = |a: i32, b: i32| -> i32 { a + b };
    let ola = || println!("olá de uma closure");
    println!("{}", dobro(21));
    println!("{}", soma(2, 3));
    ola();
}

Os parâmetros ficam entre barras | |. Os tipos são opcionais: o compilador deduz pelo uso. Com uma expressão só, as chaves também são opcionais.

2. Capturando o ambiente

fn main() {
    let taxa = 0.1;
    let com_taxa = |valor: f64| valor * (1.0 + taxa);
    println!("{:.2}", com_taxa(100.0));

    let mut cliques = 0;
    let mut clicar = || {
        cliques += 1;
        println!("clique {cliques}");
    };
    clicar();
    clicar();
    println!("total: {cliques}");
}

3. move: levar as variáveis junto

fn criar_saudacao(nome: String) -> impl Fn() -> String {
    move || format!("Olá, {nome}!")
}

fn main() {
    let saudar = criar_saudacao(String::from("Ana"));
    println!("{}", saudar());
    println!("{}", saudar());

    let lista = vec![1, 2, 3];
    let mostrar = move || println!("{:?}", lista);
    mostrar();
}

Com move, a closure vira dona do que captura. Isso é obrigatório quando a closure vai viver mais que a função que a criou (como em criar_saudacao) e quando ela vai para outra thread (Nível 3). Depois do move, lista não pode mais ser usada fora da closure.

4. Fn, FnMut, FnOnce

TraitA closure…Pode chamar
Fnsó lê o que capturouvárias vezes
FnMutmuda o que capturouvárias vezes (precisa de mut)
FnOnceconsome (move para fora) o que capturouuma vez só
fn aplicar_duas_vezes<F: Fn(i32) -> i32>(f: F, x: i32) -> i32 {
    f(f(x))
}

fn repetir<F: FnMut()>(mut f: F, vezes: u32) {
    for _ in 0..vezes {
        f();
    }
}

fn executar_uma_vez<F: FnOnce() -> String>(f: F) -> String {
    f()
}

fn main() {
    println!("{}", aplicar_duas_vezes(|n| n + 10, 1));
    let mut log = Vec::new();
    repetir(|| log.push("tic"), 3);
    println!("{:?}", log);
    let dono = String::from("posse");
    println!("{}", executar_uma_vez(move || dono));
}

5. Closures nas coleções

#[derive(Debug)]
struct Aluno {
    nome: &'static str,
    nota: u32,
}

fn main() {
    let mut turma = vec![
        Aluno { nome: "Caio", nota: 7 },
        Aluno { nome: "Ana", nota: 9 },
        Aluno { nome: "Bia", nota: 8 },
    ];
    turma.sort_by_key(|a| a.nota);
    println!("{:?}", turma.iter().map(|a| a.nome).collect::<Vec<_>>());
    turma.sort_by(|a, b| a.nome.cmp(b.nome));
    println!("{:?}", turma.iter().map(|a| a.nome).collect::<Vec<_>>());
    let minima = 8;
    turma.retain(|a| a.nota >= minima);
    println!("{:?}", turma);
}

Resumo

  • |a, b| a + b cria uma closure; tipos são opcionais.
  • Closures capturam variáveis por &, &mut (precisa de let mut) ou, com move, por posse.
  • Fn lê, FnMut muda, FnOnce consome; use-os como restrição em funções genéricas.
