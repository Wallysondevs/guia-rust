Macros declarativas

Você usa macros desde a primeira aula: println!, vec!, assert_eq!. Uma macro é código que escreve código: antes de compilar, o Rust troca a chamada pelo código que ela gera. Com macro_rules! você cria as suas, usando casamento de padrões parecido com o match.

Macro × função Uma macro recebe um número variável de argumentos, pode aceitar tipos e nomes (não só valores) e gera código na compilação. Mas é mais difícil de ler e de depurar. Se uma função resolve, prefira a função.

1. A primeira macro

macro_rules! ola {
    () => {
        println!("olá, macro!");
    };
    ($nome:expr) => {
        println!("olá, {}!", $nome);
    };
}

fn main() {
    ola!();
    ola!("Ana");
    ola!(String::from("Bia") + " e Caio");
}

3. Repetições

$( ... ),* casa “zero ou mais itens separados por vírgula”; + no lugar de * exige pelo menos um. No código gerado, $( ... )* repete a parte de dentro uma vez para cada item.

macro_rules! meu_vec {
    ( $( $x:expr ),* $(,)? ) => {
        {
            let mut v = Vec::new();
            $(
                v.push($x);
            )*
            v
        }
    };
}

macro_rules! maximo {
    ($x:expr) => { $x };
    ($x:expr, $($resto:expr),+) => {
        {
            let a = $x;
            let b = maximo!($($resto),+);
            if a > b { a } else { b }
        }
    };
}

fn main() {
    let v: Vec<i32> = meu_vec![1, 2, 3,];
    println!("{:?}", v);
    let vazio: Vec<i32> = meu_vec![];
    println!("{:?}", vazio);
    println!("máximo: {}", maximo!(4, 19, 7, 12));
}

Repare no aviso: ele aponta para dentro da macro, mas o culpado é a chamada meu_vec![]. Sem itens, o código gerado não tem nenhum push, e o mut fica sobrando. Macros geram código diferente para cada chamada, e os avisos valem para cada versão. $(,)? aceita uma vírgula opcional no fim. maximo! é recursiva: chama a si mesma com o resto da lista até sobrar um item.

4. Um mini-HashMap literal

use std::collections::HashMap;

macro_rules! mapa {
    ( $( $chave:expr => $valor:expr ),* $(,)? ) => {{
        let mut m = HashMap::new();
        $( m.insert($chave, $valor); )*
        m
    }};
}

fn main() {
    let capitais = mapa! {
        "SP" => "São Paulo",
        "RJ" => "Rio de Janeiro",
        "MG" => "Belo Horizonte",
    };
    let mut siglas: Vec<_> = capitais.keys().collect();
    siglas.sort();
    for s in siglas {
        println!("{s}: {}", capitais[s]);
    }
}

Higiene

macro_rules! cria_x {
    () => {
        let x = 100;
        println!("x dentro da macro: {x}");
    };
}

fn main() {
    let x = 1;
    cria_x!();
    println!("x no main: {x}");
}
$ cargo run

As variáveis criadas dentro de uma macro não “vazam” nem atropelam as de quem a chama: as macros do Rust são higiênicas.

Missão: Crie a macro quadrado! que recebe uma expressão e devolve ela vezes ela mesma, para imprimir quadrado de 7 = 49.

    let n = 7;
    println!("quadrado de {n} = {}", n);

macro_rules! quadrado {
    ($x:expr) => {

Resumo

  • macro_rules! define macros com braços (padrão) => { código }.
  • Fragmentos como expr, ident, ty e tt dizem o que cada $nome captura.
  • $( ... ),* e $( ... ),+ tratam listas; macros podem ser recursivas.
  • Macros são higiênicas; prefira funções quando elas bastarem.
