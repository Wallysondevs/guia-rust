Strings

Texto em Rust tem dois tipos principais, que você já conhece da aula de slices: String (dona do texto, pode crescer) e &str (uma fatia emprestada). Os dois guardam UTF-8, então acentos e emojis funcionam, mas isso tem consequências que esta aula explica.

Você vai aprender
  • A criar e aumentar uma String, e a juntar textos com + e format!.
  • Por que texto[0] não compila e como percorrer letras com chars().
  • Os métodos mais usados: split, trim, replace, contains, to_uppercase, lines.

1. Criando e aumentando

fn main() {
    let mut s = String::new();
    s.push_str("Olá");
    s.push(',');
    s.push_str(" Rust");
    println!("{s}");
    let a = "texto".to_string();
    let b = String::from("texto");
    println!("{}", a == b);
}

push_str acrescenta um texto; push, um caractere (char, com aspas simples). to_string() e String::from fazem a mesma coisa.

2. Juntando textos

fn main() {
    let nome = String::from("Ana");
    let sobrenome = String::from("Souza");
    let completo = nome + " " + &sobrenome;
    println!("{completo}");
    let cidade = "Recife";
    let uf = "PE";
    let endereco = format!("{cidade} - {uf}, {}", 2026);
    println!("{endereco}");
    let partes = ["a", "b", "c"];
    println!("{}", partes.join("-"));
}

O + consome a String da esquerda (nome não vale mais depois) e precisa de &str à direita (por isso o &sobrenome). Na prática, o format! é mais claro e não move nada.

Em UTF-8, uma letra pode ocupar de 1 a 4 bytes, então “a posição 0” é ambígua (o byte? a letra?). Em vez de adivinhar, o Rust não implementa índice em texto. Escolha o que você quer:

fn main() {
    let s = "pé🦀";
    println!("bytes: {}", s.len());
    println!("letras: {}", s.chars().count());
    for c in s.chars() {
        print!("[{c}] ");
    }
    println!();
    println!("{:?}", s.bytes().collect::<Vec<u8>>());
    println!("terceira letra: {:?}", s.chars().nth(2));
}

4. Métodos do dia a dia

fn main() {
    let linha = "  nome=Ana;idade=28;cidade=Recife  ";
    let limpa = linha.trim();
    println!("[{limpa}]");
    for campo in limpa.split(';') {
        let (chave, valor) = campo.split_once('=').unwrap();
        println!("{chave:>7}: {valor}");
    }
    println!("{}", limpa.contains("Recife"));
    println!("{}", limpa.starts_with("nome"));
    println!("{}", limpa.replace(";", " | "));
    println!("{}", "rust".to_uppercase());
    let poema = "linha um\nlinha dois\nlinha três";
    for (i, l) in poema.lines().enumerate() {
        println!("{}: {l}", i + 1);
    }
    let palavras: Vec<&str> = "  muitos   espaços aqui ".split_whitespace().collect();
    println!("{:?}", palavras);
}

Missão: Conte as palavras de "o rato roeu o paralelepípedo" e ache a maior (em letras, com chars().count()). Imprima Palavras: 5 e Maior: paralelepípedo.

fn main() {
    let frase = "o rato roeu o paralelepípedo";
}

fn main() {
    let frase = "o rato roeu o paralelepípedo";
    let palavras: Vec<&str> = frase.split_whitespace().collect();
    println!("Palavras: {}", palavras.len());
    let mut maior = palavras[0];
    for p in &palavras {
        if p.chars().count() > maior.chars().count() {
            maior = p;
        }
    }
    println!("Maior: {maior}");
}

Resumo

  • String cresce com push_str/push; junte textos com format! (ou +, que move).
  • Não há índice em texto: use chars() para letras e bytes() para bytes.
  • trim, split, lines, replace, contains e to_uppercase resolvem quase tudo.
