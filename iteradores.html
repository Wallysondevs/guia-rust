Iteradores

Um iterador entrega os itens de uma sequência, um por vez. Em Rust, eles são o jeito mais comum de processar coleções: você encadeia passos como “filtra, transforma, soma” e o compilador transforma tudo num laço tão rápido quanto um escrito à mão.

Você vai aprender
  • A diferença entre iter(), iter_mut() e into_iter().
  • Adaptadores (map, filter, zip…) são preguiçosos; consumidores (collect, sum…) fazem o trabalho.
  • A criar o seu próprio iterador implementando o trait Iterator.

1. Três jeitos de iterar

fn main() {
    let mut nums = vec![1, 2, 3];
    let soma: i32 = nums.iter().sum();
    println!("soma (emprestado): {soma}");
    for n in nums.iter_mut() {
        *n *= 10;
    }
    println!("depois do iter_mut: {:?}", nums);
    let textos: Vec<String> = nums.into_iter().map(|n| format!("#{n}")).collect();
    println!("{:?}", textos);
}

4. Consumidores

fn main() {
    let notas = [7.5, 9.0, 4.0, 8.5, 6.0];
    let total: f64 = notas.iter().sum();
    let aprovados = notas.iter().filter(|&&n| n >= 7.0).count();
    println!("média {:.2}, aprovados {aprovados}", total / notas.len() as f64);
    println!("alguém tirou 10? {}", notas.iter().any(|&n| n == 10.0));
    println!("todos acima de 3? {}", notas.iter().all(|&n| n > 3.0));
    println!("primeira abaixo de 7: {:?}", notas.iter().find(|&&n| n < 7.0));
    println!("posição do 4.0: {:?}", notas.iter().position(|&n| n == 4.0));
    let produto = (1..=5).fold(1, |acc, x| acc * x);
    println!("5! = {produto}");
    let palavras = ["sol", "paralelepípedo", "mar"];
    println!("maior: {:?}", palavras.iter().max_by_key(|p| p.chars().count()));
    let frase = palavras.iter().map(|p| p.to_uppercase()).collect::<Vec<_>>().join(" ");
    println!("{frase}");
}

O fold “dobra” a sequência num valor só: começa com 1 e, para cada item, calcula acc * x. Os &&n aparecem porque filter recebe uma referência para o item, e o item do iter() já é uma referência.

O collect sabe montar vários tipos (Vec, String, HashMap…) e precisa saber qual. Anote a variável (let v: Vec<i32>) ou use o “turbofish”: .collect::<Vec<_>>().

6. Seu próprio iterador

struct Contagem {
    atual: u32,
    fim: u32,
}

impl Iterator for Contagem {
    type Item = u32;

    fn next(&mut self) -> Option<Self::Item> {
        if self.atual < self.fim {
            self.atual += 1;
            Some(self.atual)
        } else {
            None
        }
    }
}

fn main() {
    let c = Contagem { atual: 0, fim: 5 };
    let v: Vec<u32> = c.collect();
    println!("{:?}", v);
    let soma: u32 = Contagem { atual: 0, fim: 100 }.filter(|n| n % 3 == 0).sum();
    println!("soma dos múltiplos de 3 até 100: {soma}");
}

struct Fibonacci {
    a: u64,
    b: u64,
}

impl Iterator for Fibonacci {
    type Item = u64;

    fn next(&mut self) -> Option<u64> {
        let atual = self.a;
        self.a = self.b;
        self.b += atual;
        Some(atual)
    }
}

Resumo

  • iter() empresta, iter_mut() empresta para mudar, into_iter() consome.
  • Adaptadores (map, filter, zip, take…) são preguiçosos; consumidores (collect, sum, count, fold…) executam.
  • collect precisa saber o tipo de destino.
  • Implementando next, seu tipo ganha todos os métodos de Iterator.
