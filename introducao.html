O que é Rust

Rust é uma linguagem de programação compilada: você escreve o código num arquivo .rs, o compilador confere tudo e gera um programa executável. Ela nasceu na Mozilla, ganhou a versão 1.0 em 2015 e hoje é usada em navegadores, sistemas operacionais, ferramentas de linha de comando, servidores e até no kernel do Linux.

Você vai aprender
  • O que torna o Rust diferente: segurança de memória sem coletor de lixo.
  • Quem é quem: rustc (o compilador), cargo (o gerente de projetos) e rustup (o instalador).
  • Como é um programa Rust mínimo e o que acontece quando ele roda.

A ideia: um revisor muito chato, a seu favor

Imagine que cada programa que você escreve passa por um revisor antes de ir para o mundo. Em C, o revisor deixa passar quase tudo, e os erros de memória só aparecem quando o programa trava na mão do usuário. Em Python e Java, um “zelador” (o coletor de lixo) limpa a memória enquanto o programa roda, o que é seguro, mas custa tempo. O Rust escolheu um terceiro caminho: um revisor muito exigente na compilação, que confere quem é dono de cada pedaço de memória. Se o código passa, ele é rápido como C e não precisa de zelador.

LinguagemQuem cuida da memóriaConsequência
C / C++Você, à mãoRápido, mas fácil de errar (vazamentos, uso depois de liberar)
Python / Java / GoColetor de lixo, enquanto rodaSeguro, com um custo em tempo e memória
RustO compilador, pelas regras de ownershipSeguro e rápido; o custo é aprender as regras

1. As três ferramentas

rustup
o instalador e atualizador: baixa e troca versões do Rust.
rustc
o compilador: transforma .rs em executável.
cargo
o gerente de projetos: cria, compila, roda, testa e baixa bibliotecas (crates).

No dia a dia você quase só usa o cargo, que chama o rustc por você. Mas vale ver o compilador sozinho uma vez. Este é o menor programa Rust que imprime alguma coisa:

fn main() {
    println!("Olá, Rust!");
}
$ rustc src/main.rs -o ola
$ ./ola
Olá, Rust!

O rustc não escreveu nada: em Rust, compilar sem erros é silencioso. Ele criou o executável ola, que roda sozinho, sem precisar do Rust instalado na máquina de quem for usar.

fn
declara uma função.
main
a função por onde todo programa começa.
println!
uma macro (repare no !) que imprime uma linha.
;
termina a instrução.

2. Quando dá errado: o compilador explica

Esquecer as aspas do texto é um erro comum. Veja como o compilador responde:

fn main() {
    println!(Olá, Rust!);
}
$ cargo run
   Compiling intro-erro v0.1.0 (/home/ana/projetos/intro-erro)
error: expected one of `(`, `[`, or `{`, found `<eof>`
 --> src/main.rs:2:23
  |
2 |     println!(Olá, Rust!);
  |                       ^ expected one of `(`, `[`, or `{`

error: could not compile `intro-erro` (bin "intro-erro") due to 1 previous error

Leia de cima para baixo: a linha error: diz o problema, a seta --> diz o arquivo, a linha e a coluna (src/main.rs:2:23), e o desenho aponta o lugar. Sem as aspas, o compilador leu Rust! como se fosse outra macro e ficou esperando o ( dela. A mensagem nem sempre adivinha a causa, mas sempre aponta onde o código deixou de fazer sentido. No fim, could not compile avisa que nenhum executável foi gerado. Você vai ver muitas mensagens assim neste guia, sempre reais.

3. Onde o Rust é usado

  • Ferramentas de terminal: ripgrep, fd, bat e o próprio cargo são escritos em Rust.
  • Sistemas: partes do kernel do Linux e do Windows, e componentes do Android.
  • Web e rede: servidores, proxies e WebAssembly no navegador.
  • Embarcados: microcontroladores, onde não há espaço para um coletor de lixo.

Resumo

  • Rust é compilado, rápido e seguro: o compilador confere a memória pelas regras de ownership.
  • rustup instala, rustc compila, cargo organiza o projeto.
  • Todo programa começa em fn main(); println! é uma macro.
  • As mensagens de erro mostram arquivo, linha, coluna e, muitas vezes, a correção.
