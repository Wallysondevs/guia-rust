Enums

Um enum (enumeração) é um tipo que pode ser uma entre várias possibilidades, chamadas variantes. Um semáforo é verde, amarelo ou vermelho; uma forma é um círculo ou um retângulo. Em Rust, cada variante pode carregar dados próprios, o que torna os enums muito mais poderosos que em C ou Java.

Você vai aprender
  • A declarar enums e criar valores com Tipo::Variante.
  • Variantes com dados (como tupla ou como struct) e métodos em enums.
  • O Option<T>, o jeito do Rust de dizer “pode não ter valor”, sem null.

1. Um enum simples

#[derive(Debug)]
enum Semaforo {
    Verde,
    Amarelo,
    Vermelho,
}

fn main() {
    let agora = Semaforo::Amarelo;
    let depois = Semaforo::Vermelho;
    println!("{:?} -> {:?}", agora, depois);
    println!("{:?}", Semaforo::Verde);
}

Um valor do tipo Semaforo é sempre exatamente uma das três variantes. Para agir conforme a variante, usamos o match (próxima aula). Aqui vai uma prévia, porque enums e match andam juntos.

2. Variantes com dados

#[derive(Debug)]
enum Forma {
    Circulo(f64),
    Retangulo { largura: f64, altura: f64 },
    Ponto,
}

impl Forma {
    fn area(&self) -> f64 {
        match self {
            Forma::Circulo(r) => 3.14159 * r * r,
            Forma::Retangulo { largura, altura } => largura * altura,
            Forma::Ponto => 0.0,
        }
    }
}

fn main() {
    let formas = [
        Forma::Circulo(1.0),
        Forma::Retangulo { largura: 2.0, altura: 3.0 },
        Forma::Ponto,
    ];
    for f in &formas {
        println!("{:?}: área {:.2}", f, f.area());
    }
}

Circulo carrega um f64 (o raio), Retangulo carrega dois campos com nome, e Ponto não carrega nada. Todos são do mesmo tipo Forma, então cabem no mesmo array. E enums também têm impl e métodos.

3. Option<T>: um valor que pode não existir

Rust não tem null. Quando um valor pode faltar, o tipo é Option<T>, um enum da biblioteca padrão com duas variantes:

enum Option<T> {
    Some(T),  // tem um valor do tipo T
    None,     // não tem valor
}
fn dividir(a: f64, b: f64) -> Option<f64> {
    if b == 0.0 {
        None
    } else {
        Some(a / b)
    }
}

fn main() {
    let r1 = dividir(10.0, 4.0);
    let r2 = dividir(1.0, 0.0);
    println!("{:?} {:?}", r1, r2);
    let numeros = [3, 8, 12];
    println!("{:?}", numeros.iter().position(|&n| n == 8));
    println!("{:?}", numeros.iter().position(|&n| n == 99));
}

O <T> significa “de qualquer tipo”: Option<f64>, Option<String>… Muitas funções da biblioteca padrão devolvem Option, como position, que procura um item.

fn main() {
    let talvez: Option<i32> = Some(5);
    let total = match talvez {
        Some(n) => n + 1,
        None => 0,
    };
    println!("{total}");
}

fn main() {
}

fn raiz_inteira(n: i32) -> Option<i32> {
    if n < 0 {
        return None;
    }
    for r in 0..=n {
        if r * r == n {
            return Some(r);
        }
    }
    None
}

fn main() {
    println!("{:?}", raiz_inteira(16));
    println!("{:?}", raiz_inteira(-4));

Resumo

  • enum define um tipo com variantes; um valor é sempre exatamente uma delas.
  • Variantes podem carregar dados: Circulo(f64), Retangulo { largura, altura }.
  • Option<T> (Some(v) ou None) substitui o null e obriga a tratar a ausência.
