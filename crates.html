Crates e dependências

Um crate é a unidade que o compilador compila: um programa (crate binário, com main) ou uma biblioteca (crate de biblioteca, sem main). Um pacote é o que o cargo new cria: um Cargo.toml com um ou mais crates. E o crates.io é o repositório público onde a comunidade publica bibliotecas.

Você vai aprender
  • A adicionar uma biblioteca do crates.io com cargo add e o papel do Cargo.lock.
  • A ter src/lib.rs e src/main.rs no mesmo pacote.
  • A usar uma biblioteca sua, de outra pasta, com path.

1. Usando uma biblioteca do crates.io

A biblioteca padrão não tem gerador de números aleatórios. O crate mais usado para isso é o rand. O cargo add procura a versão mais nova e escreve no Cargo.toml:

fn main() {
    let d: u32 = rand::random_range(1..=6);
    println!("o dado deu {d}");
}

Cargo.lock

cargo update
atualiza o Cargo.lock para as versões compatíveis mais novas.
Achando crates

Procure em crates.io ou em lib.rs. A documentação de qualquer crate publicado fica em docs.rs/nome-do-crate. Alguns muito usados: serde (JSON e outros formatos), clap (argumentos de linha de comando), regex, chrono (datas) e tokio (programação assíncrona).

2. Biblioteca e programa no mesmo pacote

Se o pacote tem src/lib.rs, ele também é uma biblioteca, com o mesmo nome do pacote. O main.rs usa a biblioteca como se fosse um crate de fora. É o jeito comum de organizar: a lógica fica na biblioteca (fácil de testar) e o main só cuida da entrada e da saída.

use calculadora::{media, Estatisticas};

fn main() {
    let dados = [4.0, 8.0, 15.0, 16.0, 23.0, 42.0];
    println!("média: {:.2}", media(&dados));
    let e = Estatisticas::de(&dados);
    println!("{:?}", e);
}
//! Pequena biblioteca de estatística.

/// Média aritmética de uma fatia de números.
pub fn media(v: &[f64]) -> f64 {
    v.iter().sum::<f64>() / v.len() as f64
}

#[derive(Debug)]
pub struct Estatisticas {
    pub minimo: f64,
    pub maximo: f64,
    pub media: f64,
}

impl Estatisticas {
    pub fn de(v: &[f64]) -> Self {
        let minimo = v.iter().cloned().fold(f64::INFINITY, f64::min);
        let maximo = v.iter().cloned().fold(f64::NEG_INFINITY, f64::max);
        Estatisticas { minimo, maximo, media: media(v) }
    }
}

3. Uma biblioteca sua, em outra pasta

Para reaproveitar uma biblioteca entre projetos, crie-a com cargo new --lib e aponte para a pasta com path no Cargo.toml de quem usa:

$ rm -rf saudacao app-saudacao
$ cargo new --lib saudacao
    Creating library `saudacao` package
note: see more `Cargo.toml` keys and their definitions at https://doc.rust-lang.org/cargo/reference/manifest.html
$ cat saudacao/src/lib.rs
pub fn add(left: u64, right: u64) -> u64 {
    left + right
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn it_works() {
        let result = add(2, 2);
        assert_eq!(result, 4);
    }
}
$ printf 'pub fn ola(nome: &str) -> String {\n    format!("Olá, {nome}!")\n}\n' > saudacao/src/lib.rs
$ cargo new app-saudacao
    Creating binary (application) `app-saudacao` package
note: see more `Cargo.toml` keys and their definitions at https://doc.rust-lang.org/cargo/reference/manifest.html
$ cd app-saudacao
$ cargo add --path ../saudacao
      Adding saudacao (local) to dependencies
     Locking 1 package to highest Rust 1.100.0 compatible version
$ printf 'fn main() {\n    println!("{}", saudacao::ola("Ana"));\n}\n' > src/main.rs
$ cargo run
   Compiling saudacao v0.1.0 (/home/ana/projetos/saudacao)
   Compiling app-saudacao v0.1.0 (/home/ana/projetos/app-saudacao)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.13s
     Running `target/debug/app-saudacao`
Olá, Ana!

O cargo new --lib já cria uma função de exemplo com um teste (você vê testes mais adiante). O cargo add --path escreve no Cargo.toml algo como saudacao = { path = "../saudacao" }. Para projetos com várias partes que evoluem juntas, o cargo também tem workspaces: uma pasta com um Cargo.toml que lista vários pacotes e compila todos com um target só.

4. Quando dá errado: crate que não está no Cargo.toml

fn main() {
    let d: u32 = rand::random_range(1..=6);
    println!("{d}");
}
$ cargo run
   Compiling sem-dependencia v0.1.0 (/home/ana/projetos/sem-dependencia)
error[E0433]: cannot find module or crate `rand` in this scope
 --> src/main.rs:2:18
  |
2 |     let d: u32 = rand::random_range(1..=6);
  |                  ^^^^ use of unresolved module or unlinked crate `rand`
  |
  = help: if you wanted to use a crate named `rand`, use `cargo add rand` to add it to your `Cargo.toml`

For more information about this error, try `rustc --explain E0433`.
error: could not compile `sem-dependencia` (bin "sem-dependencia") due to 1 previous error

Sem a linha no Cargo.toml, o compilador não sabe o que é rand (E0433). A correção é o cargo add rand.

Missão: Simule uma pequena biblioteca num módulo: crie mod estatistica com pub fn mediana(v: &mut Vec<i32>) -> i32 (ordene e pegue o do meio). Para vec![9, 2, 7, 4, 11], imprima Mediana: 7.

fn main() {
    let mut v = vec![9, 2, 7, 4, 11];
}

mod estatistica {
    pub fn mediana(v: &mut Vec<i32>) -> i32 {
        v.sort();
        v[v.len() / 2]
    }
}

fn main() {
    let mut v = vec![9, 2, 7, 4, 11];
    println!("Mediana: {}", estatistica::mediana(&mut v));
}

Resumo

  • Crate = unidade de compilação (binário ou biblioteca); pacote = Cargo.toml + crates.
  • cargo add nome adiciona do crates.io; o Cargo.lock fixa as versões exatas.
  • src/lib.rs faz do pacote uma biblioteca; path = "../pasta" usa uma biblioteca local.
