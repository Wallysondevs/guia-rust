Tipos de dados

Rust é uma linguagem de tipagem estática: o compilador precisa saber o tipo de cada valor antes de rodar. Na maior parte das vezes ele descobre sozinho (isso se chama inferência), mas às vezes você precisa dizer. Nesta aula você conhece os tipos básicos.

Você vai aprender
  • Os tipos escalares: inteiros, ponto flutuante, bool e char.
  • Os tipos compostos: tuplas e arrays.
  • A conversar entre tipos com as e o que acontece num overflow ou num índice fora do array.

fn main() {
    let a = 42;            // i32, o padrão
    let b: u8 = 255;       // anotação de tipo
    let c = 1_000_000i64;  // sufixo e separador _
    let d = 0xff;          // hexadecimal
    println!("{a} {b} {c} {d}");
    println!("u8 vai de {} a {}", u8::MIN, u8::MAX);
    println!("i32 vai até {}", i32::MAX);
    println!("divisão inteira: {}, resto: {}", 7 / 2, 7 % 2);
}

2. Ponto flutuante, bool e char

fn main() {
    let x = 2.5;           // f64, o padrão
    let y: f32 = 1.0 / 3.0;
    let ligado = true;
    let letra = 'R';
    let emoji = '🦀';
    println!("{x} {y} {ligado} {letra} {emoji}");
    println!("7.0 / 2.0 = {}", 7.0 / 2.0);
    println!("raiz de 2 = {:.4}", 2.0_f64.sqrt());
}
$ cargo run

O char usa aspas simples e guarda um caractere Unicode (4 bytes), inclusive acentos e emojis. Texto, com aspas duplas, é outra coisa (&str e String), que você vê nas aulas de slices e de strings.

Rust não converte números sozinho: i32 + f64 não existe. O E0277 diz que não há implementação de soma de inteiro com float. Converta você mesmo com as:

fn main() {
    let inteiro = 10;
    let fracao = 2.5;
    println!("{}", inteiro as f64 + fracao);
    println!("{}", 3.99_f64 as i32);
    println!("{}", 300_i32 as u8);
    println!("{}", 'A' as u8);
}
$ cargo run
   Compiling as v0.1.0 (/home/ana/projetos/as)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s
     Running `target/debug/as`
12.5
3
44
65

Cuidado: as não arredonda (3.99 vira 3) e, ao caber num tipo menor, corta os bits (300 vira 44, porque 300 − 256 = 44).

4. Overflow: estourar o tamanho do tipo

fn main() {
    let mut nivel: u8 = 250;
    for _ in 0..10 {
        nivel += 1;
    }
    println!("{nivel}");
}
$ cargo run
   Compiling overflow v0.1.0 (/home/ana/projetos/overflow)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s
     Running `target/debug/overflow`

thread 'main' (167193) panicked at src/main.rs:4:9:
attempt to add with overflow
note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace

No perfil dev, o Rust confere estouros e o programa para com um panic (attempt to add with overflow), em vez de seguir com um número errado. Para escolher o comportamento, há métodos como checked_add, wrapping_add e saturating_add:

fn main() {
    let n: u8 = 250;
    println!("{:?}", n.checked_add(10));
    println!("{}", n.wrapping_add(10));
    println!("{}", n.saturating_add(10));
}
$ cargo run

5. Tuplas

Uma tupla agrupa valores de tipos diferentes, com tamanho fixo:

fn main() {
    let pessoa: (&str, i32, f64) = ("Ana", 28, 1.65);
    println!("nome: {}", pessoa.0);
    let (nome, idade, altura) = pessoa;
    println!("{nome} tem {idade} anos e {altura} m");
    let vazio = ();
    println!("{:?}", vazio);
}
$ cargo run
   Compiling tuplas v0.1.0 (/home/ana/projetos/tuplas)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s
     Running `target/debug/tuplas`
nome: Ana
Ana tem 28 anos e 1.65 m
()

Acesse com .0, .1… ou desestruture com let (a, b, c) = …. A tupla vazia () se chama unit: é o “nada” que funções sem retorno devolvem.

6. Arrays

fn main() {
    let notas = [7, 8, 10, 6];
    let zeros = [0; 5];
    let meses: [&str; 3] = ["jan", "fev", "mar"];
    println!("primeira nota: {}", notas[0]);
    println!("quantidade: {}", notas.len());
    println!("{:?} {:?}", zeros, meses);
}

Um array tem tamanho fixo e todos os elementos do mesmo tipo. O tipo se escreve [tipo; tamanho]. Para listas que crescem, use Vec (aula de coleções). E se você pedir um índice que não existe?

fn main() {
    let notas = [7, 8, 10, 6];
    let i = notas.len() + 2;
    println!("{}", notas[i]);
}
$ cargo run
   Compiling indice v0.1.0 (/home/ana/projetos/indice)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s

Panic: index out of bounds. O Rust confere o índice e para o programa em vez de ler memória que não é do array. Esse é um dos bugs que, em C, viram falhas de segurança.

Resumo

  • Inteiros (i32 padrão, u8, usize…), floats (f64 padrão), bool e char (Unicode).
  • Rust não mistura tipos sozinho: converta com as, sabendo que ele trunca.
  • Overflow e índice fora do array viram panic no modo dev, não bugs silenciosos.
  • Tuplas agrupam tipos diferentes; arrays, valores do mesmo tipo com tamanho fixo.
