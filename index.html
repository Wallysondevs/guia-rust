Tutorial Rust

Aprenda Rust do zero, em português, como numa escola: cada aula ensina um assunto, explica o código pedaço por pedaço e mostra a resposta de verdade do compilador. Todos os exemplos deste guia foram compilados e rodados com o rustc 1.100.0, e os erros aparecem exatamente como o compilador escreveu.

Comece aqui ❯

A primeira aula é O que é Rust. Depois vêm a instalação, o cargo e o primeiro programa.

O que é este guia

Rust é uma linguagem de programação rápida como C e C++, mas que impede, já na compilação, uma família inteira de bugs: uso de memória já liberada, ponteiro nulo, corrida de dados entre threads. O preço é aprender algumas regras novas, principalmente o ownership (posse) e o borrowing (empréstimo). Este guia ensina essas regras com calma, com exemplos pequenos e com os erros reais que o compilador mostra quando a gente quebra uma delas.

O guia é para quem já viu um pouco de programação (uma variável, um if, uma função) em qualquer linguagem. Não precisa saber C. Os exemplos acompanham a Ana, que estuda Rust no computador notebook, com os projetos na pasta /home/ana/projetos.

O texto está em português do Brasil. O código, as palavras-chave e as mensagens do compilador ficam em inglês, como o Rust escreve. As mensagens de erro não são traduzidas: aparecem exatamente como o cargo mostrou, com a explicação em português logo depois.

Como estudar

  1. Leia com calma. Leia a ideia, o código e a saída. Não pule as partes “Quando dá errado”: os erros do compilador ensinam muito.
  2. Rode os exemplos. Crie um projeto com cargo new, cole o código no src/main.rs e rode cargo run.
  3. Faça as missões. Cada caixa Missão pede um programa. Escreva, rode com cargo run e cole a saída na caixa: ela confere o código e a saída.
  4. Erre de propósito. Mude uma linha, quebre uma regra e leia o que o compilador diz. É o jeito mais rápido de ficar amigo dele.
A regra de ouro

O compilador do Rust é exigente, mas é um professor paciente: quase toda mensagem de erro diz o que está errado, onde e, muitas vezes, como consertar (as linhas help:). Leia a mensagem inteira antes de mexer no código.
