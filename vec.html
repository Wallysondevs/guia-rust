Vetores (Vec)

O Vec<T> (vetor) é a lista que cresce: guarda vários valores do mesmo tipo, um depois do outro, e aumenta conforme você acrescenta itens. É a coleção mais usada em Rust.

Você vai aprender
  • A criar vetores com Vec::new() e vec![], acrescentar e tirar itens.
  • A diferença entre v[i] (panic se não existir) e v.get(i) (devolve Option).
  • A percorrer, alterar, ordenar e filtrar o vetor.

1. Criando e acrescentando

fn main() {
    let mut compras: Vec<String> = Vec::new();
    compras.push(String::from("arroz"));
    compras.push(String::from("feijão"));
    let numeros = vec![10, 20, 30];
    println!("{:?} ({} itens)", compras, compras.len());
    println!("{:?} vazio? {}", numeros, numeros.is_empty());
    let mut pilha = vec![1, 2, 3];
    let topo = pilha.pop();
    println!("tirei {:?}, sobrou {:?}", topo, pilha);
}

O vec![…] é uma macro que cria o vetor já com valores. Com Vec::new(), o vetor nasce vazio e o tipo vem da anotação (Vec<String>) ou do primeiro push.

Use v[i] quando o índice com certeza existe (e um erro seria um bug). Use v.get(i) quando pode não existir, por exemplo um número digitado pelo usuário.

3. Percorrendo e alterando

fn main() {
    let mut precos = vec![10.0, 25.5, 8.0];
    for p in &precos {
        print!("{p} ");
    }
    println!();
    for p in &mut precos {
        *p *= 1.1;
    }
    println!("{:.2?}", precos);
    let total: f64 = precos.iter().sum();
    println!("total: {total:.2}");
}

for p in &v empresta cada item para leitura. for p in &mut v empresta para escrita: o *p (desreferência) acessa o valor apontado pela referência para poder mudá-lo. Sem o &, o for consome o vetor, que não pode ser usado depois.

4. Quando dá errado: mudar o vetor dentro do for

fn main() {
    let mut v = vec![1, 2, 3];
    for x in &v {
        if *x == 2 {
            v.push(4);
        }
    }
    println!("{:?}", v);
}

5. Ordenar, procurar, remover

fn main() {
    let mut v = vec![5, 3, 8, 3, 1, 8, 2];
    v.sort();
    println!("ordenado: {:?}", v);
    v.dedup();
    println!("sem repetidos seguidos: {:?}", v);
    v.retain(|&x| x != 5);
    println!("sem o 5: {:?}", v);
    v.insert(0, 100);
    let removido = v.remove(1);
    println!("{:?} (removi {removido})", v);
    println!("tem 8? {}", v.contains(&8));
    v.reverse();
    println!("invertido: {:?}", v);
    let mut nomes = vec!["Caio", "ana", "Bia"];
    nomes.sort_by_key(|n| n.to_lowercase());
    println!("{:?}", nomes);
}

MétodoO que faz
push(x) / pop()põe no fim / tira do fim (Option)
insert(i, x) / remove(i)põe / tira na posição i
sort(), sort_by_key(f)ordena
dedup()remove repetidos vizinhos (ordene antes)
retain(f)mantém só os que passam no teste
contains(&x)tem esse valor?
len(), is_empty(), clear()tamanho, vazio?, esvaziar

Resumo

  • Vec::new() ou vec![…]; push/pop no fim.
  • v[i] dá panic se não existir; v.get(i) devolve Option.
  • for x in &v lê, for x in &mut v altera (*x); não mude o vetor enquanto o percorre.
