Box<T>: dados no heap

Um smart pointer (ponteiro inteligente) é uma struct que se comporta como referência, mas é dona do valor e faz algo a mais. O mais simples é o Box<T>: ele guarda o valor no heap e, na pilha, fica só um ponteiro. Quando o Box sai de escopo, o valor no heap é liberado.

Quando usar Box
  • Tipos recursivos, cujo tamanho o compilador não consegue calcular (listas, árvores).
  • Guardar valores de tipos diferentes que implementam o mesmo trait: Box<dyn Trait>.
  • Mover um valor grande sem copiar os bytes (só o ponteiro anda).

1. O básico

fn main() {
    let numero = Box::new(41);
    let soma = *numero + 1;
    println!("numero = {numero}");
    println!("soma = {soma}");
    println!("tamanho do Box na pilha: {} bytes", std::mem::size_of::<Box<i32>>());
}

Box::new coloca o valor no heap. Para usar o valor, *numero desreferencia (segue o ponteiro). O println! já faz isso sozinho. Na pilha, o Box ocupa 8 bytes: o tamanho de um endereço numa máquina de 64 bits.

2. Tipos recursivos

Uma lista ligada em que cada nó contém o próximo nó parece natural, mas não compila:

enum Lista {
    No(i32, Lista),
    Fim,
}

fn main() {
    let _l = Lista::Fim;
}

  | ^^^^^^^^^^
2 |     No(i32, Lista),

O compilador tenta calcular o tamanho de Lista: ela contém uma Lista, que contém outra Lista… infinito. A dica (help) é exatamente a solução: pôr o próximo nó dentro de um Box, que tem tamanho fixo.

enum Lista {
    No(i32, Box<Lista>),
    Fim,
}

use Lista::{Fim, No};

fn soma(l: &Lista) -> i32 {
    match l {
        No(valor, resto) => valor + soma(resto),
        Fim => 0,
    }
}

fn main() {
    let l = No(1, Box::new(No(2, Box::new(No(3, Box::new(Fim))))));
    println!("soma = {}", soma(&l));
}

Uma árvore binária

#[derive(Debug)]
enum Arvore {
    Folha,
    No(Box<Arvore>, i32, Box<Arvore>),
}

impl Arvore {
    fn inserir(self, v: i32) -> Arvore {
        match self {
            Arvore::Folha => Arvore::No(Box::new(Arvore::Folha), v, Box::new(Arvore::Folha)),
            Arvore::No(esq, x, dir) => {
                if v < x {
                    Arvore::No(Box::new(esq.inserir(v)), x, dir)
                } else {
                    Arvore::No(esq, x, Box::new(dir.inserir(v)))
                }
            }
        }
    }

    fn em_ordem(&self, saida: &mut Vec<i32>) {
        if let Arvore::No(esq, x, dir) = self {
            esq.em_ordem(saida);
            saida.push(*x);
            dir.em_ordem(saida);
        }
    }
}

fn main() {
    let mut a = Arvore::Folha;
    for v in [5, 2, 8, 1, 9, 3] {
        a = a.inserir(v);
    }
    let mut ordenado = Vec::new();
    a.em_ordem(&mut ordenado);
    println!("{:?}", ordenado);
}
$ cargo run
   Compiling arvore v0.1.0 (/home/ana/projetos/arvore)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.11s
     Running `target/debug/arvore`
[1, 2, 3, 5, 8, 9]

Repare em esq.inserir(v): esq é um Box<Arvore>, mas o método é de Arvore. O Box implementa o trait Deref, então o Rust segue o ponteiro sozinho (auto-deref). Para tirar o valor de dentro, *esq move o conteúdo para fora do Box.

3. Box<dyn Trait>: tipos diferentes na mesma coleção

trait Forma {
    fn area(&self) -> f64;
    fn nome(&self) -> String;
}

struct Quadrado(f64);
struct Circulo(f64);

impl Forma for Quadrado {
    fn area(&self) -> f64 { self.0 * self.0 }
    fn nome(&self) -> String { format!("quadrado de lado {}", self.0) }
}

impl Forma for Circulo {
    fn area(&self) -> f64 { 3.14159 * self.0 * self.0 }
    fn nome(&self) -> String { format!("círculo de raio {}", self.0) }
}

fn main() {
    let formas: Vec<Box<dyn Forma>> = vec![
        Box::new(Quadrado(2.0)),
        Box::new(Circulo(1.0)),
        Box::new(Quadrado(3.0)),
    ];
    let mut total = 0.0;
    for f in &formas {
        println!("{:<22} área {:.2}", f.nome(), f.area());
        total += f.area();
    }
    println!("total: {total:.2}");
}
$ cargo run

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.13s
     Running `target/debug/dyn-trait`
quadrado de lado 2     área 4.00

quadrado de lado 3     área 9.00

Um Vec só guarda elementos de um tipo. Box<dyn Forma> é esse tipo único: “um ponteiro para qualquer coisa que implemente Forma”. A chamada f.area() é decidida em tempo de execução (dynamic dispatch), por uma tabela de métodos guardada junto com o ponteiro.

    // monte a lista 10 -> 20 -> 30 -> 40

enum Lista {
    No(i32, Box<Lista>),
    Fim,
}

use Lista::{Fim, No};

    match l {
        No(_, resto) => 1 + tamanho(resto),
        Fim => 0,

Missão: Crie a struct Vaca e implemente Animal para ela (som muu), e coloque uma vaca chamada Mimosa no vetor. A saída deve ter Rex diz au e Mimosa diz muu.

trait Animal {
    fn nome(&self) -> String;
    fn som(&self) -> String;
}

struct Cachorro;

impl Animal for Cachorro {
    fn nome(&self) -> String { "Rex".to_string() }
    fn som(&self) -> String { "au".to_string() }
}

fn main() {
    let bichos: Vec<Box<dyn Animal>> = vec![Box::new(Cachorro)];
    for b in &bichos {
        println!("{} diz {}", b.nome(), b.som());
    }
}

trait Animal {

struct Cachorro;
struct Vaca;

impl Animal for Cachorro {

    fn nome(&self) -> String { "Mimosa".to_string() }

Resumo

  • Box::new(v) guarda v no heap; o Box é dono do valor e o libera ao sair de escopo.
  • *b desreferencia; métodos funcionam direto graças ao Deref.
  • Tipos recursivos precisam de Box para ter tamanho conhecido (erro E0072).
  • Box<dyn Trait> junta tipos diferentes que implementam o mesmo trait.
