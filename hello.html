Olá, mundo e println!

Todo programa Rust começa pela função main. Para mostrar algo na tela, usamos a macro println!, que imprime um texto e pula de linha. Nesta aula você aprende a imprimir textos, números e variáveis, a formatar a saída e a comentar o código.

Você vai aprender
  • A anatomia do fn main() e do println!.
  • Os marcadores {}, {nome}, {:?}, largura e casas decimais.
  • A diferença entre print!, println! e eprintln!, e os comentários // e /* */.

1. O programa mínimo

fn main() {

}

2. Marcadores: {}

O primeiro argumento do println! é o texto de formato. Cada {} é trocado por um valor, na ordem. Você também pode escrever o nome de uma variável dentro das chaves.

fn main() {
    let nome = "Ana";
    let idade = 28;
    println!("{} tem {} anos", nome, idade);
    println!("{nome} tem {idade} anos");
    println!("{0} e {1}; de novo {0}", "pão", "café");
    println!("Chaves literais: {{ e }}");
}
$ cargo run
   Compiling marcadores v0.1.0 (/home/ana/projetos/marcadores)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.09s
     Running `target/debug/marcadores`
Ana tem 28 anos
Ana tem 28 anos
pão e café; de novo pão
Chaves literais: { e }

Para escrever uma chave de verdade, dobre: {{ e }}.

3. Largura, alinhamento e casas decimais

fn main() {
    let pi = 3.14159265;
    println!("[{:.2}]", pi);
    println!("[{:8.3}]", pi);
    println!("[{:<8}]", "esq");
    println!("[{:>8}]", "dir");
    println!("[{:^8}]", "meio");
    println!("[{:05}]", 42);
    println!("{:b} {:x} {:o}", 10, 255, 8);
}

4. {:?}: o formato de depuração

Alguns valores, como listas, não têm um jeito “bonito” padrão de aparecer. Para eles existe o {:?} (Debug), e o {:#?}, que quebra em várias linhas:

fn main() {
    let notas = [7, 9, 10];
    let par = ("Ana", 28);
    println!("{:?}", notas);
    println!("{:?}", par);
    println!("{:#?}", par);
}
$ cargo run
   Compiling debug v0.1.0 (/home/ana/projetos/debug)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.10s
     Running `target/debug/debug`
[7, 9, 10]
("Ana", 28)
(
    "Ana",
    28,
)

5. print!, eprintln! e comentários

// Comentário de linha: o compilador ignora.
/* Comentário de bloco:
   pode ocupar várias linhas. */
fn main() {
    print!("sem ");
    print!("pular ");
    println!("linha");
    eprintln!("isto vai para a saída de erro (stderr)");
}
$ cargo run
   Compiling prints v0.1.0 (/home/ana/projetos/prints)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.09s
     Running `target/debug/prints`
sem pular linha
isto vai para a saída de erro (stderr)

O print! não pula linha. O eprintln! escreve na saída de erro: no terminal aparece igual, mas dá para separar com redirecionamento (cargo run 2> erros.txt). Comentários com /// são de documentação e aparecem no cargo doc.

Quando dá errado

Se o número de {} não bate com o número de valores, o código nem compila:

fn main() {
    println!("{} e {}", "um");
}
$ cargo run
   Compiling erro-args v0.1.0 (/home/ana/projetos/erro-args)
error: 2 positional arguments in format string, but there is 1 argument
 --> src/main.rs:2:15
  |
2 |     println!("{} e {}", "um");
  |               ^^   ^^   ----

error: could not compile `erro-args` (bin "erro-args") due to 1 previous error

O compilador conta os marcadores: dois {} e um só argumento. Muitas linguagens só descobririam isso na hora de rodar.

fn main() {
    let pi = 3.14159;
    // imprima com 3 casas
}

    let pi = 3.14159;
    println!("Pi vale {:.3}", pi);

Resumo

  • println! imprime e pula linha; print! não pula; eprintln! vai para a saída de erro.
  • {} mostra o valor; {nome} usa uma variável; {:?} é o formato de depuração.
  • {:.2}, {:>8}, {:05} controlam casas, alinhamento e zeros.
  • Marcadores e argumentos são conferidos na compilação.
