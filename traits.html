Traits

Um trait descreve um comportamento que vários tipos podem ter: “sabe se apresentar”, “tem área”, “pode ser impresso”. Você declara os métodos no trait e cada tipo implementa do seu jeito. É parecido com interfaces de Java e C#.

Você vai aprender
  • A declarar um trait e implementá-lo com impl Trait for Tipo.
  • Métodos com implementação padrão e o trait Display da biblioteca padrão.
  • A aceitar “qualquer tipo que implemente o trait” com impl Trait e dyn Trait.

1. Declarando e implementando

trait Animal {
    fn nome(&self) -> String;
    fn som(&self) -> String;
}

struct Cachorro;
struct Gato {
    apelido: String,
}

impl Animal for Cachorro {
    fn nome(&self) -> String {
        String::from("Cachorro")
    }
    fn som(&self) -> String {
        String::from("au au")
    }
}

impl Animal for Gato {
    fn nome(&self) -> String {
        format!("Gato {}", self.apelido)
    }
    fn som(&self) -> String {
        String::from("miau")
    }
}

fn main() {
    let c = Cachorro;
    let g = Gato { apelido: String::from("Frajola") };
    println!("{} faz {}", c.nome(), c.som());
    println!("{} faz {}", g.nome(), g.som());
}

2. Quando dá errado: faltou um método

trait Forma {
    fn area(&self) -> f64;
    fn perimetro(&self) -> f64;
}

struct Quadrado(f64);

impl Forma for Quadrado {

3. Métodos com implementação padrão

trait Apresentavel {
    fn nome(&self) -> String;

    fn apresentar(&self) -> String {
        format!("Olá, eu sou {}!", self.nome())
    }
}

struct Pessoa(String);
struct Robo(u32);

impl Apresentavel for Pessoa {
    fn nome(&self) -> String {
        self.0.clone()
    }
}

impl Apresentavel for Robo {
    fn nome(&self) -> String {
        format!("RX-{}", self.0)
    }
    fn apresentar(&self) -> String {
        format!("BIP. UNIDADE {} ATIVA.", self.nome())
    }
}

fn main() {
    println!("{}", Pessoa(String::from("Ana")).apresentar());
    println!("{}", Robo(42).apresentar());
}

4. Um trait da biblioteca padrão: Display

O {:?} usa o trait Debug (que dá para derivar). O {} usa o Display, que você implementa à mão, porque só você sabe como o seu tipo deve aparecer para o usuário:

use std::fmt;

struct Dinheiro {
    centavos: u64,
}

impl fmt::Display for Dinheiro {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "R$ {},{:02}", self.centavos / 100, self.centavos % 100)
    }
}

fn main() {
    let preco = Dinheiro { centavos: 1999 };
    println!("Preço: {preco}");
    let texto = preco.to_string();
    println!("{} caracteres", texto.len());
}

5. Aceitando qualquer tipo com o trait

trait Forma {
    fn area(&self) -> f64;
    fn nome(&self) -> &str;
}

struct Circulo(f64);
struct Retangulo(f64, f64);

impl Forma for Circulo {
    fn area(&self) -> f64 { 3.14159 * self.0 * self.0 }
    fn nome(&self) -> &str { "círculo" }
}

impl Forma for Retangulo {
    fn area(&self) -> f64 { self.0 * self.1 }
    fn nome(&self) -> &str { "retângulo" }
}

fn descrever(f: &impl Forma) {
    println!("{} com área {:.2}", f.nome(), f.area());
}

fn main() {
    descrever(&Circulo(1.0));
    descrever(&Retangulo(2.0, 3.0));

    let formas: Vec<Box<dyn Forma>> = vec![Box::new(Circulo(2.0)), Box::new(Retangulo(1.0, 5.0))];
    let total: f64 = formas.iter().map(|f| f.area()).sum();
    println!("área total: {total:.2}");
}
$ cargo run

círculo com área 3.14
retângulo com área 6.00

  • &impl Forma: “uma referência para qualquer tipo que implemente Forma”. O compilador gera uma versão da função para cada tipo usado (rápido).
  • Box<dyn Forma>: um objeto de trait. Permite misturar tipos diferentes no mesmo vetor; o método certo é escolhido na hora de rodar. O Box você estuda no Nível 3.

Resumo

  • trait Nome { fn metodo(&self); } declara; impl Nome for Tipo { … } implementa.
  • Faltar método obrigatório é o E0046; métodos podem ter implementação padrão.
  • Display controla o {} e dá o to_string().
  • impl Trait aceita qualquer tipo com o trait; Box<dyn Trait> mistura tipos diferentes.
