Option em detalhe

Você já viu que Option<T> é Some(valor) ou None. Nesta aula você aprende a abrir um Option com segurança e a transformá-lo sem escrever um match para cada passo. Esses métodos aparecem em todo código Rust.

Você vai aprender
  • unwrap e expect, e o panic que eles causam com None.
  • unwrap_or, unwrap_or_else e unwrap_or_default, para ter um valor padrão.
  • map, and_then, filter e ok_or, para encadear transformações.

1. unwrap e expect: “confia em mim”

fn main() {
    let nomes = ["Ana", "Bia", "Caio"];
    let primeiro = nomes.first().unwrap();
    println!("primeiro: {primeiro}");
    let pos = nomes.iter().position(|&n| n == "Bia").expect("Bia deveria estar na lista");
    println!("Bia está na posição {pos}");
}

unwrap() devolve o valor de dentro do Some. expect("…") faz o mesmo, com uma mensagem sua. Mas se o valor for None…

fn main() {
    let vazio: Vec<i32> = Vec::new();
    let maior = vazio.iter().max().expect("a lista não pode estar vazia");
    println!("{maior}");
}

…o programa para com um panic e mostra a sua mensagem. Use unwrap/expect só quando um None for realmente impossível (ou em testes e protótipos). Prefira expect: a mensagem ajuda muito a achar o problema.

2. Valores padrão

fn main() {
    let configurada: Option<u32> = None;
    let porta = configurada.unwrap_or(8080);
    println!("porta: {porta}");

    let nome: Option<String> = None;
    println!("nome: '{}'", nome.unwrap_or_default());

    let talvez: Option<u32> = Some(3);
    let n = talvez.unwrap_or_else(|| {
        println!("calculando o padrão...");
        10
    });
    println!("n: {n}");
}
$ cargo run
   Compiling padrao v0.1.0 (/home/ana/projetos/padrao)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.11s
     Running `target/debug/padrao`
porta: 8080
nome: ''
n: 3
MétodoCom None devolve
unwrap_or(v)o valor v
unwrap_or_else(|| …)o resultado da closure (só calcula se precisar)
unwrap_or_default()o padrão do tipo: 0, "", false…

O || { … } é uma closure, uma função sem nome. Você vê closures com calma no fim deste nível. Repare que calculando o padrão... não apareceu: como talvez era Some(3), a closure nem rodou.

3. Transformando: map, and_then, filter

fn main() {
    let texto: Option<&str> = Some("rust");
    let maiusculo = texto.map(|t| t.to_uppercase());
    println!("{:?}", maiusculo);

    let nada: Option<&str> = None;
    println!("{:?}", nada.map(|t| t.len()));

    let entrada = Some("42");
    let numero = entrada.and_then(|s| s.parse::<i32>().ok());
    println!("{:?}", numero);
    let invalido = Some("quarenta");
    println!("{:?}", invalido.and_then(|s| s.parse::<i32>().ok()));

    let par = Some(8).filter(|n| n % 2 == 0);
    let impar = Some(7).filter(|n| n % 2 == 0);
    println!("{:?} {:?}", par, impar);
}
$ cargo run

  • map: se for Some(x), aplica a função e devolve Some(resultado); se for None, continua None.
  • and_then: como map, mas a função já devolve um Option (evita Some(Some(…))).
  • filter: mantém o Some só se a condição valer.

4. Perguntando e convertendo

fn main() {
    let a: Option<i32> = Some(1);
    let b: Option<i32> = None;
    println!("{} {}", a.is_some(), b.is_none());
    let r: Result<i32, &str> = b.ok_or("valor ausente");
    println!("{:?}", r);
    if let Some(v) = a {
        println!("a tem {v}");
    }
}

O ok_or transforma um Option num Result, o tipo da próxima aula: None vira um erro com a mensagem que você escolher.

Resumo

  • unwrap/expect abrem o Option, mas dão panic com None.
  • unwrap_or, unwrap_or_else, unwrap_or_default dão um valor padrão.
  • map, and_then, filter transformam sem abrir; ok_or vira Result.
