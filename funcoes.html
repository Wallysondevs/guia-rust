Funções

Funções dividem o programa em pedaços com nome. Em Rust elas são declaradas com fn, os parâmetros sempre têm tipo e o valor devolvido vem depois de uma seta ->. O detalhe mais importante desta aula é pequeno: um ponto e vírgula a mais ou a menos muda o que a função devolve.

Você vai aprender
  • A declarar funções com parâmetros tipados e retorno.
  • A diferença entre instrução e expressão.
  • Por que x + 1 devolve e x + 1; não, com o erro real.

1. Declarando e chamando

fn main() {
    saudar("Ana");
    saudar("Bruno");
    mostrar_soma(3, 4);
}

fn saudar(nome: &str) {
    println!("Oi, {nome}!");
}

fn mostrar_soma(a: i32, b: i32) {
    println!("{a} + {b} = {}", a + b);
}
$ cargo run
   Compiling funcoes v0.1.0 (/home/ana/projetos/funcoes)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s
     Running `target/debug/funcoes`
Oi, Ana!
Oi, Bruno!
3 + 4 = 7

A ordem não importa: main pode chamar funções declaradas depois dela. Nomes de função usam snake_case (minúsculas com _). Cada parâmetro precisa do tipo: a: i32.

fn dobro(x: i32) -> i32 {

3. Instrução × expressão

Uma instrução faz algo e não produz valor (let y = 6;). Uma expressão produz um valor (5 + 6, uma chamada de função, um bloco { }). O ponto e vírgula transforma uma expressão em instrução. Até um bloco tem valor:

fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("y vale {y}");
}
$ cargo run

4. Quando dá errado: o ; que sobra

fn mais_um(x: i32) -> i32 {
    x + 1;
}

fn main() {
    println!("{}", mais_um(5));
}
$ cargo run

  |
1 | fn mais_um(x: i32) -> i32 {
  |    -------            ^^^ expected `i32`, found `()`
  |    |

Com o ;, a última linha virou instrução, e o corpo não devolve nada (ou melhor, devolve ()). Mas a assinatura promete um i32: erro E0308. A mensagem é ótima: ela diz implicitly returns `()` e sugere, no help, apagar o ponto e vírgula.

5. return antecipado

Para sair antes do fim, use return. Por estilo, só se usa return para saídas antecipadas; no fim, a expressão sem ;.

fn classificar(nota: u32) -> &'static str {
    if nota >= 7 {
        return "aprovado";
    }
    "recuperação"
}

fn main() {
    println!("{}", classificar(9));
    println!("{}", classificar(5));
}
$ cargo run
   Compiling return v0.1.0 (/home/ana/projetos/return)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s
     Running `target/debug/return`
aprovado
recuperação

O &'static str é um texto fixo, escrito no programa. O 'static é um lifetime, assunto do Nível 2. Por enquanto, leia como “texto que vive o programa inteiro”.

6. Devolvendo vários valores com tupla

fn divisao(a: i32, b: i32) -> (i32, i32) {
    (a / b, a % b)
}

fn main() {

Resumo

  • fn nome(p: Tipo) -> Retorno { … }; parâmetros sempre tipados.
  • A última expressão sem ; é o valor devolvido; return é para sair antes.
  • Um ; a mais faz a função devolver () e dá o erro E0308.
  • Blocos { } também são expressões e têm valor.
